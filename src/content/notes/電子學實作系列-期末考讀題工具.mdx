## 準備方向

### 需要的物理其實很少

整份題庫用到的物理，只有下表上半部。高中物理考不好的單元（力學、運動學）完全不會出現。

| 需要的概念 | 一句話定義 | 數學上是什麼 |
| --- | --- | --- |
| 電荷 $q$ | 守恆量，一顆電子是 $-1.6\times10^{-19}\ \text{C}$ | 守恆量 |
| 電流 $I$ | 每秒通過某截面的電荷，單位 A | 流率 $\frac{dq}{dt}$ |
| 電位、電壓 $V$ | 每單位電荷的位能；電壓是兩點的電位差，「接地」是選定的零點 | 位能函數；只有差值有意義 |
| 電阻 $R$ | $V = IR$ | 線性函數的比例常數 |
| 電容 $C$ | $Q = CV$，所以 $I = C\frac{dV}{dt}$；直流穩態時不流電流 | 一階 ODE 的來源 |
| 功率 $P$ | $P = VI$ | 能量對時間的導數 |
| 熱電壓 $V_T$ | 室溫的熱能換算成電壓，$V_T = \frac{kT}{q} = 26\ \text{mV}$ | 所有指數裡的尺度常數 |
| 克希荷夫電流定律（KCL） | 流進一個節點的電流總和等於流出 | 節點上的守恆方程 |
| 克希荷夫電壓定律（KVL） | 繞一圈回到原點，電壓升降總和為 0 | 位能函數繞閉路徑積分為 0 |

| 不需要的 | 原因 |
| --- | --- |
| 力學、運動學、能量守恆 | 題庫沒有任何一題用到 |
| 電磁感應、磁場 | 變壓器只當成「把正弦振幅換一個值」的黑盒子（[Ex 3-27](/notes/電子學實作系列-期末考講義練習題#example-3-27半波整流器要多大的濾波電容第-31-頁)） |
| 半導體的物理推論 | CH2 考的是代公式，公式與常數已整理在題庫的[考前速記](/notes/電子學實作系列-期末考講義練習題#考前速記各章公式一頁) |

### 刷題的四步

1. 遮住解答自己做，卡住超過 10 分鐘才看。
2. 對答案時把錯誤歸到下表其中一類，錯題本只記類別和題號，不重抄整題。
3. 某一類錯最多，就回頭補那一層：名詞卡、讀圖五步、題幹解碼表或流程。
4. 做一個變形：只改一個條件（電阻加倍、$\beta$ 改 50、溫度升高），先預測答案往哪邊走，再算一次驗證。

## 整門課只有一個流程：假設 → 求解 → 驗證

**前提盤點**：二極體、BJT、MOS 都是非線性元件，它們的電流電壓關係是分段函數。每一段叫一個「工作區」，題目問的電路，答案取決於元件落在哪一段。

**數學對應**：這就是分段函數的分情況討論。不知道落在哪一段時，先假設一段、用該段公式解，再檢查解出來的值是否真的落在這一段；矛盾就換一段重解。

| 元件 | 工作區 | 該段公式 | 驗證條件 | 例題 |
| --- | --- | --- | --- | --- |
| 二極體 | 導通 | $V_D = V_{D,on} = 0.8\ \text{V}$（定電壓模型）或 $I_D = I_S\exp\frac{V_D}{V_T}$ | 解出 $I_D > 0$ | [Ex 2-21](/notes/電子學實作系列-期末考講義練習題#example-2-21指數模型-vs-定電壓模型第-6466-頁)、[Ex 3-27](/notes/電子學實作系列-期末考講義練習題#example-3-27半波整流器要多大的濾波電容第-31-頁) |
| 二極體 | 截止 | $I_D = 0$ | 解出 $V_D < V_{D,on}$ | [Ex 3-1](/notes/電子學實作系列-期末考講義練習題#example-3-1哪種串聯接法能導通第-6-頁) |
| BJT | 主動區 | $I_C = I_S\exp\frac{V_{BE}}{V_T}$、$I_B = \frac{I_C}{\beta}$ | $V_C \ge V_B$（基–集逆偏） | [Ex 4-5](/notes/電子學實作系列-期末考講義練習題#example-4-5簡單偏壓級的輸出電壓第-17-頁)、[Ex 4-7](/notes/電子學實作系列-期末考講義練習題#example-4-7驗證主動區與集極電阻上限第-2527-頁)、[Ex 4-11](/notes/電子學實作系列-期末考講義練習題#example-4-11加上集極電阻後的電壓增益第-4041-頁) |
| BJT | 軟飽和 | 仍用主動區公式 | $V_B - V_C \le 400\ \text{mV}$ | [Ex 4-16](/notes/電子學實作系列-期末考講義練習題#example-4-16保證軟飽和的-rcr_crc-與-vccv_ccvcc-關係第-5253-頁) |
| BJT | 飽和 | 主動區公式失效 | $V_B - V_C > 400\ \text{mV}$ | [Ex 4-11](/notes/電子學實作系列-期末考講義練習題#example-4-11加上集極電阻後的電壓增益第-4041-頁) 的陷阱 |
| MOS | 截止 | $I_D = 0$ | $V_{GS} < V_{TH}$ | CH6 |
| MOS | 三極管區 | $I_D = \mu_n C_{ox}\frac{W}{L}\left[(V_{GS}-V_{TH})V_{DS} - \frac12 V_{DS}^2\right]$ | $V_{DS} < V_{GS} - V_{TH}$ | CH6 |
| MOS | 飽和區 | $I_D = \frac12\mu_n C_{ox}\frac{W}{L}(V_{GS}-V_{TH})^2$ | $V_{DS} \ge V_{GS} - V_{TH}$ | CH6 |

BJT 的「飽和」和 MOS 的「飽和」意思相反：BJT 飽和是壞事（放大失效），MOS 飽和才是放大器要的區域。名稱撞在一起是歷史因素，看到時先確認是哪一種元件。

### 小訊號就是一階泰勒展開

偏壓點解出來之後，題目常接著問「輸入加一個小變化，輸出變多少」。這一段的數學是在偏壓點把非線性函數換成切線。

**推導**：以 BJT 為例，對 $I_C = I_S\exp\frac{V_{BE}}{V_T}$ 在偏壓點 $V_{BE}$ 做一階展開：

$$
\begin{aligned}
I_C(V_{BE} + v_{be}) &\approx I_C(V_{BE}) + \frac{dI_C}{dV_{BE}}\,v_{be}\\
\frac{dI_C}{dV_{BE}} &= \frac{1}{V_T}\,I_S\exp\frac{V_{BE}}{V_T} = \frac{I_C}{V_T} \equiv g_m\\
\Delta I_C &= g_m\,v_{be},\qquad v_{out} = -R_C\,\Delta I_C = -g_m R_C\,v_{be}\;\Rightarrow\; A_V = -g_m R_C .
\end{aligned}
$$

增益公式就是連鎖律：$\frac{dV_{out}}{dV_{in}} = \frac{dV_{out}}{dI_C}\cdot\frac{dI_C}{dV_{BE}}$。二極體的小訊號電阻 $r_d = \frac{V_T}{I_D}$ 是同一個導數取倒數（[Ex 3-18](/notes/電子學實作系列-期末考講義練習題#example-3-18偏壓-1-ma-的二極體對小擾動的反應第-19-頁)、[Ex 3-19](/notes/電子學實作系列-期末考講義練習題#example-3-19小訊號正弦加在二極體上第-2122-頁)）；MOS 的 $g_m$ 是平方律對 $V_{GS}$ 的導數 $\mu_n C_{ox}\frac{W}{L}(V_{GS}-V_{TH})$。

**因次檢查**：

$$
[\,g_m\,] = \frac{[\,I_C\,]}{[\,V_T\,]} = \frac{\text{A}}{\text{V}} = \text{S},\qquad [\,g_m R_C\,] = \text{S}\cdot\Omega = 1 .
$$

$g_m$ 是電導（電阻的倒數），乘上電阻後無因次，電壓增益本來就該是純數。算出來帶單位，就是哪裡錯了。

**自測**：偏壓電流 $I_C$ 加倍，$g_m$ 和 $r_\pi = \frac{\beta}{g_m}$ 各怎麼變？

:::tip{collapsible title="答案"}
$g_m = \frac{I_C}{V_T}$ 與 $I_C$ 成正比，所以加倍；$r_\pi = \frac{\beta}{g_m}$ 減半。這也是 [Ex 4-10](/notes/電子學實作系列-期末考講義練習題#example-4-10麥克風訊號的小訊號參數第-3839-頁) 的 $I_C = 6.92\ \text{mA}$ 讓 $r_\pi$ 只剩 375 Ω 的原因。
:::

### 示範一：[Ex 2-21](/notes/電子學實作系列-期末考講義練習題#example-2-21指數模型-vs-定電壓模型第-6466-頁) 二極體串電阻

![Example 2-21 電路：VX 串聯 R1 = 1 kΩ 與二極體 D1，電流 IX，二極體跨壓 VD](/note-images/ec-week1-ch2/33-example-2-21-circuit.png)

| 步驟 | 這題看到什麼 | 寫下什麼 |
| --- | --- | --- |
| 1 認元件 | 電壓源 $V_X$、電阻 $R_1$、二極體 $D_1$（三角形朝下，順著 $I_X$ 方向） | $V_{R} = I_X R_1$；$I_X = I_S\exp\frac{V_D}{V_T}$ |
| 2 標節點 | 三個節點：$V_X$ 正端、$R_1$ 與 $D_1$ 之間、接地；只有一個迴路，所以只有一個電流 $I_X$ | 未知數：$I_X$、$V_D$ |
| 3 找已知 | $V_X = 3\ \text{V}$ 或 $1\ \text{V}$、$R_1 = 1\ \text{k}\Omega$、$I_S = 10^{-16}\ \text{A}$ | — |
| 4 列方程 | 沿迴路 KVL | $V_X = I_X R_1 + V_D$ |
| 5 判區域 | $V_X$ 大於 0.8 V，假設導通；解出 $I_X > 0$，假設成立 | — |

步驟 4 和二極體方程合起來，消去 $I_X$ 就是一個不動點問題：

$$
\begin{aligned}
V_D &= V_T\ln\frac{I_X}{I_S} = V_T\ln\frac{V_X - V_D}{R_1 I_S} \equiv g(V_D)\\
\lvert g'(V_D)\rvert &= \frac{V_T}{V_X - V_D} = \frac{26\ \text{mV}}{2.2\ \text{V}} \approx 0.012 .
\end{aligned}
$$

$\lvert g'\rvert$ 遠小於 1，是很強的壓縮映射，所以題庫解答「猜 750 mV 疊代兩輪」就收斂。講義說的「疊代法」就是數學上的不動點疊代。

# 電子學實作系列：實驗器材速查

實驗課會反覆用到三樣核心儀器：**示波器**（看波形）、**萬用電表**（量單一數值：電壓／電流／電阻）、**直流電源供應器**（給電路供電）。這份筆記整理自課程提供的三份原廠使用手冊（`DSOX1200X_EDUX1052A_示波器使用者指南.pdf`、`GDM-532_萬用電表使用手冊.pdf`、`GPE-1326_2323_3323_4323_多輸出直流電源供應器使用手冊.pdf`，見 `docs/references/電子學實作系列/第一週/`），只保留「第一次動手做實驗前該知道的事」，不是逐頁翻譯——手冊裡的進階功能（韌體、遠端控制、校正）不在這裡。

## 示波器（Keysight DSOX1200X / EDUX1052A 系列）

示波器做的事，是把一個隨時間變化的電壓「畫」成螢幕上的波形——多數電路故障或行為異常，光看電表量到的單一數字看不出來，但示波器一畫出波形就一目了然。

### 面板一眼看懂

| 分區 | 功能 |
| --- | --- |
| 電源開關 | 左下角，按一下開機／關機 |
| Horizontal（水平區） | 時間/格旋鈕、`[Acquire]` 擷取鍵、縮放鍵 |
| Vertical（垂直區） | 每個類比通道各一組電壓/格旋鈕、通道開關鍵（有色，對應螢幕波形顏色） |
| Trigger（觸發區） | 觸發位準旋鈕、`[Trigger]` 鍵、`[Force]` 強制觸發鍵 |
| 執行控制 | `[Run/Stop]`（綠＝執行中、紅＝已停止）、`[Single]` 單次觸發 |
| 其他常用鍵 | `[Default Setup]`（回復原廠設定）、`[Auto Scale]`（自動調整）、`[Meas]`（量測）、`[Cursors]`（游標）、`[Help]` |
| 前面板接頭 | 類比通道 BNC 輸入（1MΩ 阻抗）、Demo/Probe Comp 端子＋接地端子、USB 主機埠 |

### 第一次開機到看到波形

1. 接上電源線（100–240 VAC 自動偵測），**務必用有接地的插座**，桌面擺放時左右各留 2 吋、頂部與後方留 4 吋散熱空間。
2. 測試棒的 BNC 端接到要用的通道，鉤狀端接觸待測電路的測試點，**接地夾夾到該電路的接地點**。
3. 按 `[Auto Scale]`，示波器會自動判斷有訊號的通道、調整刻度並顯示波形。
4. 如果波形出現但方波邊緣看起來圓弧或有尖峰，代表探棒需要補償（見下一節）。

### 探棒補償：為什麼第一次一定要做

每一支被動測試棒都必須針對所接的通道做**補償（compensation）**，否則量出來的波形會有明顯失真。補償步驟：

1. 探棒從要用的通道接到前面板 **Demo/Probe Comp** 端子，接地夾接到旁邊的接地端子。
2. 按 `[Default Setup]` → `[Auto Scale]`（會針對這個內建方波訊號自動調好刻度）。
3. 按該通道鍵 → 通道功能表 → 「測試棒」→「測試棒檢查」，依畫面指示用**非金屬工具**調整測試棒上的修整電容器。

| 補償狀態 | 方波看起來的樣子 |
| --- | --- |
| 適當補償 | 頂角平整 |
| 過度補償 | 頂角有突起（overshoot） |
| 補償不足 | 頂角呈圓弧下垂 |

每支測試棒、每個通道都要各自補償一次；如果測試棒本身可調衰減比（如 10:1/1:1 切換），補償時**務必設為 10:1**。

### 基本刻度與觸發設定

- **水平（時間/格）**：轉動時基旋鈕調整。除了一般的「標準」模式，還有 **XY 模式**（通道1當X軸、通道2當Y軸，畫伏特對伏特圖，可用來測相位差）與**滾動模式**（給很慢的低頻訊號用）。
- **垂直（電壓/格）**：每個通道各自一顆旋鈕。**通道耦合**選 DC 可看到完整波形（含直流偏移）；選 AC 會濾掉直流成分（10Hz 高通），適合波形疊著很大直流偏壓、只想看交流變化量的情況（例如放大器輸出訊號疊在偏壓點上）。**測試棒衰減設定一定要跟實際探棒相符**（1:1 或 10:1），設錯的話讀出來的電壓會差 10 倍。
- **觸發（Trigger）**：最常用的是**邊緣觸發**——選來源通道、選斜率（上升/下降），示波器會固定在訊號通過某個電壓值（觸發位準）的那一瞬間畫面，波形才會穩定顯示而不是一直亂跑。觸發位準旋鈕按下去可快速抓到訊號的 50% 值。

### 常用自動量測（按 `[Meas]` 叫出）

| 量測項目 | 意義 |
| --- | --- |
| 峰-峰值（Vpp） | 波形最大值減最小值 |
| 平均值 | 所有取樣點的平均 |
| DC RMS ／ AC RMS | 均方根值（含／不含直流成分，AC RMS 適合看電源雜訊等） |
| 週期／頻率 | 兩個同極性邊緣間的時間／其倒數 |
| 占空比（Duty Cycle） | 高電位時間占整個週期的比例 |
| 上升／下降時間 | 訊號從 10% 爬升到 90%（或反向）所需時間 |
| 延遲／相位 | 兩個通道之間的時間差／相位差（角度） |

### 接地安全鐵律（最容易踩的坑）

> 示波器**所有通道**的測試棒接地夾，實際上都連到示波器機箱同一個接地參考電位。如果同時用兩個通道量測兩個「接地不共通」的電路（例如各自接不同電源供應器的電路），把兩個接地夾都夾上去，等於用示波器機殼把這兩個原本獨立的接地點短路在一起——輕則量測結果錯誤，重則損壞電路或儀器。**如果真的需要同時量測兩個不同參考電位的點，要用差動探棒，不能直接拿兩支一般探棒的接地夾去接。**

- 類比輸入最大電壓：**150 Vrms、200 Vpk**，超過會損壞儀器。
- 示波器機箱**不可浮接**——測試棒接地引線要接到示波器機箱與電源線的接地系統，破壞這個接地會有觸電風險。

## 萬用電表（GW Instek GDM-532）

萬用電表一次只給你**一個數字**（電壓、電流、電阻……擇一），量法簡單但也最容易因為「接錯孔位」或「用錯量測方式」而燒毀保險絲或損壞電路，是三樣儀器裡新手最常出包的一台。

### 面板與端子

- **旋鈕**：切換電壓／電流／電阻／二極體／通斷／電容／溫度／頻率／OFF 等模式。
- **4 顆按鈕**：`SEL`（同檔位下切換子功能，例如 DCV/ACV）、`RANGE`（手動/自動測距）、`REL Δ`（相對值歸零）、`HOLD`（數據保持，長按開背光）。
- **4 個輸入端子**：
  - **mA/A**：量測較大電流（最高 10A），**內建可恢復式保險絲（10A/1000V 快熔）**。
  - **µA**：量測微安等級的小電流，獨立孔位。
  - **COM**：所有量測共用的參考端，黑棒固定插這裡。
  - **VΩ**：電壓、電阻、電容、二極體、通斷、頻率、溫度共用，紅棒插這裡。

### 量電壓（DCV/ACV）

1. 旋鈕轉到電壓檔（不確定範圍就先選最大量程，顯示 "OL" 代表超過量程再往下調）。
2. 紅棒插 **VΩ**、黑棒插 **COM**。
3. 探棒**並聯**接觸待測兩端讀值，用 `SEL` 切換 DCV/ACV。

輸入電壓**不可超過 1000V**；表頭輸入阻抗約 10MΩ，量測高阻抗電路（>10kΩ）時本身的負載效應可能造成誤差。

### 量電流（DCA/ACA）——重點是「串聯」

1. 紅棒依電流大小插 **mA/A** 或 **µA** 孔，黑棒插 **COM**。
2. **務必把電表串聯接入電路**（斷開電路一點、把電表接進這個缺口），**絕對不能像量電壓一樣並聯接到電源或元件兩端**。
3. `SEL` 切換 DC/AC，讀值。

> **保險絲燒斷最常見的原因**：把電流檔的探棒誤當電壓表一樣並聯接到電源兩端——這等於直接短路，會瞬間燒斷 mA/A 孔內建的保險絲。量測前務必先確認：旋鈕檔位對不對、孔位插對了沒、電路先斷電再接線。測量接近 10A 時，單次量測應少於 10 秒，且每次間隔要大於 15 分鐘，避免過熱。

### 量電阻（Ω）——一定要斷電量測

1. 紅棒插 **VΩ**、黑棒插 **COM**，並聯接觸待測電阻兩端。
2. **量測前務必先關閉電路電源，並把電路上所有電容放電完畢**。

原因：電表量電阻時是自己送一股小電流到待測物上、量測壓降换算成電阻值；如果電路還帶電或電容還有殘餘電荷，量出來的值會錯，甚至可能損壞電表。電阻檔耐壓上限也遠低於電壓檔（**60VDC / 30VAC**）。量低電阻時，探棒本身也有約 0.1~0.2Ω 的電阻，精確量測前可先把兩支探棒短接，記下這個「探棒電阻」再從讀值裡扣掉。

### 二極體測試 / 通斷測試

- **二極體測試**：探棒接觸 PN 接面兩端，正接（紅棒接陽極）矽二極體會顯示約 **0.5~0.8V**（正向導通電壓）；接反或元件損壞則顯示 "OL"——可以用這個功能快速判斷二極體方向或好壞。
- **通斷測試（continuity）**：電阻 ≤30Ω 判定良好導通、蜂鳴器連續響；>420Ω 判定斷路。適合快速檢查導線、PCB 走線是否斷路。兩者都要求**先斷電並放電**才能測。

### 安全與規格重點

- **CAT 等級**：CAT II 1000V／CAT III 600V；量測 CAT III 環境（如配電箱）要裝回探棒護套。
- 量測 AC 30Vrms 或 DC 60V 以上時要特別小心，屬於有觸電風險的等級。
- **量測中途不要轉動旋鈕**，容易損壞電表；先斷電、轉好旋鈕、確認孔位，再開始量測。

| 模式 | 量測範圍 | 精度 |
| --- | --- | --- |
| DCV | 9.999mV~999.9V | ±(0.7%讀值+8 digit)~±(0.5%+3) |
| ACV | 9.999mV~999.9V | ±(1%+3)~±(0.8%+3)，頻率響應 45~400Hz |
| 電阻 | 999.9Ω~99.99MΩ | ±(0.8%+5)~±(2.0%+5) |
| DC 電流 | 999.9µA~9.999A | ±(0.8%+3)~±(1.0%+3) |

## 直流電源供應器（GW Instek GPE 系列）

課程用的是 GPE-1326／2323／3323／4323 其中一台——數字代表輸出組數與規格不同，**先看機身面板上的實際型號**再對照下表，因為旋鈕數量與功能會不一樣（1326 是單通道、沒有串並聯功能；2323/3323/4323 都支援 Series/Parallel 切換）。

| 型號 | 輸出組數 | 各組規格 |
| --- | --- | --- |
| GPE-1326 | 1 組 | 0~32V / 0~6A（電壓、電流各有粗調＋微調旋鈕） |
| GPE-2323 | 2 組（CH1、CH2 皆可調） | 各 0~32V / 0~3A |
| GPE-3323 | 3 組（CH1/CH2 可調＋CH3 固定） | CH1/CH2 各 0~32V/0~3A；CH3 固定 5V/5A |
| GPE-4323 | 4 組（全部可調） | CH1/CH2 各 0~32V/0~3A；CH3 0~5V/1A；CH4 0~15V/1A |

### 基本操作：先設電流限制，再接電路

1. **先不要接電路**，用 Voltage 旋鈕轉到要輸出的電壓值。
2. 用 Current 旋鈕設定**電流限制（current limit）**。
3. 接好待測電路到對應通道的 +/− 端子。
4. 按 **Output** 鍵開啟輸出，LCD 會顯示 **CV** 或 **CC** 圖示表示目前運作模式。

**為什麼一定要先設電流限制、再接電路**：電流限制值就是這台電源「允許輸出的電流上限」。實驗接線階段最容易不小心短路（例如麵包板跳線插錯），如果電流限制設得夠低、夠合理，短路發生時電源會自動頂到限流值、把電壓壓低，而不是無限制地灌電流燒毀元件或麵包板走線——這個操作順序本身就是一種保護機制。

### CV（定電壓）／CC（定電流）模式

- **CV 模式**：負載電流低於你設定的限流值時，電源維持電壓恆定，電流隨負載變化。
- **CC 模式**：負載電流一旦達到限流值，電源自動切成電流恆定，這時電壓會被壓低以維持電流不超過設定值。
- 兩者**自動雙向切換**，不需要手動介入；LCD 對應通道會顯示 CV 或 CC 圖示（僅在該通道輸出 ON 時顯示）。

### 多組輸出的串聯與並聯（GPE-2323/3323/4323 才有）

面板上的 Series/Parallel 鍵可在 Independent／Series／Parallel 三態間切換，**切換時輸出會自動關閉**（安全機制）。CH1 永遠是 Master、CH2 是 Slave，機器內部自動接好，不需要自己接跳線。

- **串聯（Series Tracking）**：輸出規格變成 0~64V / 0~3A，適合需要比單組更高電壓的情況；也可以用 CH1(−) 當共同地線，做出對稱的正負電源。
- **並聯（Parallel Tracking）**：輸出規格變成 0~32V / 0~6A，適合需要比單組更高電流的情況，負載只接在 CH1 端子上。

### 安全與操作習慣

- **開機前務必先確認機背 AC 電壓選擇器**（100/120/220/230V）設定正確，選錯可能損壞機器。
- 每組輸出都有獨立紅(+)/黑(−) banana 端子，另有一個 GND 端子（接大地，非某組輸出的一部分）。
- **改接線、換模式、或關機前，先按 Output 鍵關閉輸出**，再動端子或關電源總開關——機器本身在切換模式或觸發過壓保護（OVP）時也會自動關輸出，這是同一個安全邏輯。
- 面板的 Lock 功能可鎖定電壓/電流旋鈕避免實驗中誤觸，但 **Output 鍵不受鎖定影響**，確保緊急時仍能一鍵關輸出。
- 規格量測前提是**開機預熱至少 30 分鐘**，環境溫度 20~30°C 下數值才準。

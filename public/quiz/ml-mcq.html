第 1 週 - 機器學習簡介

W1-1

代理人透過與環境互動、依獎勵訊號試錯學習，屬於哪一類學習？ An agent learns by trial and error from a reward signal while interacting with an environment. Which category of learning is this?

  • A強化式學習 Reinforcement learning
  • B監督式學習 Supervised learning
  • C非監督式學習 Unsupervised learning
  • D半監督學習 Semi-supervised learning
正解 A
小抄 §1 學習類型與任務第一面

強化式學習的特徵是「互動、試錯、依獎勵調整策略」，目標是讓累積的總獎勵最大化，資料不是事先備好的成對輸入與標籤。

第二項是最容易誤選的：獎勵訊號看起來像標籤，但兩者性質不同——標籤直接告訴模型「正確答案是什麼」，獎勵只告訴代理人「這一步好不好」，而且往往要等好幾步之後才知道。

考的觀念：有沒有標籤、標籤從哪裡來，是四種學習方式的分界。

W1-2

分類與迴歸的差別是什麼？ What is the difference between classification and regression?

  • A分類用監督式學習，迴歸用非監督式學習 Classification is supervised learning, regression is unsupervised learning
  • B分類的特徵是離散的，迴歸的特徵是連續的 Classification has discrete features, regression has continuous features
  • C分類的標籤是離散類別，迴歸的標籤是連續數值 Classification has discrete class labels, regression has continuous numeric labels
  • D分類需要特徵縮放，迴歸不需要 Classification needs feature scaling, regression does not
正解 C
小抄 §1 學習類型與任務第一面

兩者都是監督式學習，差別在標籤的型態：離散類別是分類，連續數值是迴歸。

第二項把標籤講成特徵，是最常見的混淆——特徵是離散或連續，與任務屬於分類還是迴歸無關。判斷任務類型永遠先看「要預測的那一欄長什麼樣」。

考的觀念：看標籤，不是看特徵。

W1-3

可訓練參數與超參數的差別是什麼？ What is the difference between trainable parameters and hyperparameters?

  • A前者是整數，後者是浮點數 The former are integers, the latter floating-point numbers
  • B前者訓練中自動學出，後者訓練前由人設定 The former are learned automatically during training, the latter set by a human beforehand
  • C前者由人設定，後者訓練中自動學出 The former are set by a human, the latter learned automatically during training
  • D兩者相同，只是不同框架的稱呼 They are the same thing, named differently by different frameworks
正解 B
小抄 §1 學習類型與任務第一面

可訓練參數（例如權重）是訓練過程中從資料學出來的；超參數（例如學習率、樹深、kkk 值）必須在訓練開始前由人決定。

第三項把兩者對調，是最容易記反的一組。一個實用的判準：訓練跑完之後值會變的是可訓練參數，值不會變的是超參數。

考的觀念：誰在訓練過程中被更新，誰就是可訓練參數。

W1-4

特徵選取與特徵提取的差別是什麼？ What is the difference between feature selection and feature extraction?

  • A前者在訓練前做，後者在訓練後做 The former is done before training, the latter after training
  • B前者用於分類，後者用於迴歸 The former is for classification, the latter for regression
  • C兩者都會產生全新的特徵欄位 Both produce entirely new feature columns
  • D前者從原始特徵挑子集，後者組合轉換成新特徵 The former picks a subset of the original features, the latter combines and transforms them into new ones
正解 D
小抄 §1 學習類型與任務第一面

特徵選取是從既有欄位中挑一個子集，欄位本身不變，因此保留了原來的物理意義；特徵提取則是把特徵組合轉換成新的表示（例如 PCA），欄位本身已經改變，新特徵通常不再有直觀意義。

第三項只對一半——會產生全新欄位的只有特徵提取。這個差別在需要對人解釋模型時特別重要：選取後還能說「是因為這一欄」，提取後就不行了。

考的觀念：欄位有沒有被重新組合，是兩者的分界。

W1-5

一個 epoch 指的是什麼？ What does one epoch mean?

  • A訓練資料完整跑過一輪 One full pass over the training data
  • B權重更新一次 One update of the weights
  • C處理完一個批次的資料 Finishing one batch of data
  • D完成一次完整的交叉驗證 Completing one full round of cross-validation
正解 A
小抄 §1 學習類型與任務第一面

一個 epoch 是訓練資料被完整看過一遍。

第二項是最容易混淆的：一個 epoch 裡的權重更新次數取決於訓練方式——批次梯度下降一個 epoch 只更新一次，隨機梯度下降則每看一筆就更新一次，一個 epoch 會更新樣本數那麼多次。兩者的 epoch 定義相同，更新次數卻差很多。

考的觀念：epoch 數的是「資料被看過幾遍」，不是「權重被更新幾次」。

W1-6

過擬合與欠擬合分別對應什麼？ What do overfitting and underfitting each correspond to?

  • A過擬合對應高偏差，欠擬合對應高變異 Overfitting means high bias, underfitting means high variance
  • B兩者都對應高變異，差別在訓練集表現 Both mean high variance; they differ in training set performance
  • C過擬合對應高變異，欠擬合對應高偏差 Overfitting means high variance, underfitting means high bias
  • D兩者都對應高偏差，差別在測試集表現 Both mean high bias; they differ in test set performance
正解 C
小抄 §6 過擬合／欠擬合與正則化第一面

過擬合是模型把訓練資料的細節（含雜訊）也記住了，訓練集表現好但驗證與測試集明顯變差，表現為高變異；欠擬合是模型太簡單，連訓練資料本身的規律都學不好，表現為高偏差。

第一項把兩者對調，是最容易記反的一組。可以從字面接：變異衡量的是「換一份訓練資料結果會差多少」，記太多細節的模型自然變異大。

考的觀念：訓練集表現好不好，是區分兩者的第一個問題。

W1-7

No Free Lunch 定理告訴我們什麼？ What does the No Free Lunch theorem tell us?

  • A越複雜的模型在所有任務上都越好 The more complex a model is, the better it does on every task
  • B不存在一個分類器能在所有場景都表現最好 No single classifier performs best in every scenario
  • C訓練資料越多，任何模型都會收斂到相同結果 With enough training data, every model converges to the same result
  • D所有演算法的計算成本本質上相同 All algorithms cost essentially the same to compute
正解 B
小抄 §1 學習類型與任務第一面

沒有哪一個演算法能在所有問題上勝出，因此實務上要針對手上的問題比較多種演算法，而不是預設某個模型最強。

第一項正是這條定理要否定的直覺。第三項也不對：不同演算法的歸納偏好不同，資料再多也不會讓它們收斂到同一個解。

考的觀念：模型選擇是任務相依的，沒有通用最佳解。

W1-8

梯度下降與隨機梯度下降的主要差別是什麼？ What is the main difference between gradient descent and stochastic gradient descent?

  • A前者用於分類，後者用於迴歸 The former is for classification, the latter for regression
  • B前者會收斂，後者不會收斂 The former converges, the latter does not
  • C前者需要標籤，後者不需要 The former needs labels, the latter does not
  • D前者每次用全部樣本算梯度，後者每次只用一筆估計 The former computes the gradient from all samples, the latter estimates it from one at a time
正解 D
小抄 §4 梯度下降家族第一面

梯度下降每更新一次得掃完整份資料，梯度準確但慢；隨機梯度下降每看一筆就更新一次，梯度只是估計值、損失曲線比較毛躁，但更新快得多，也天然支援線上學習。

第二項說得太絕對：隨機梯度下降照樣會收斂，只是會在最低點附近抖動而不是穩穩停住——而這個抖動反而有機會跳出淺的局部低點。

考的觀念：差別在「一次更新用了多少資料」。

W1-9

Iris 資料表中一朵花的紀錄、花瓣長度欄、花的種類，依序是什麼？ In an Iris table, what are one flower record, the petal-length column, and the flower species, respectively?

  • A樣本、特徵、標籤 Sample, feature, label
  • B特徵、標籤、樣本 Feature, label, sample
  • C標籤、樣本、特徵 Label, sample, feature
  • D三者都是特徵 All three are features
正解 A
小抄 §10 定義、資料型態與 Iris第一面

Sample 為一筆觀測，feature 為輸入屬性，target／label 為預測答案。

教材依據：L1 p23–24、p31。

W1-10

S、M、L 衣服尺寸屬於哪種資料？ What type of data are clothing sizes S, M, and L?

  • A連續數值 Continuous numerical data
  • B無序的名義類別 Unordered nominal categories
  • C有順序的類別 Ordered categories
  • D無標籤影像 Unlabeled images
正解 C
小抄 §10 定義、資料型態與 Iris第一面

尺寸有順序，屬 ordinal；顏色、血型等無大小關係者是 nominal。

W1-11

依課堂比較，為何 min-max 縮放可能讓其他資料擠在很小區間？ According to the classroom comparison, why can min-max scaling compress most observations into a very small interval?

  • A會先移除所有離群值 It removes all outliers first
  • B極端最大／最小值會拉大縮放的分母 Extreme minimum or maximum values enlarge the denominator
  • C它會自動變成常態分布 It automatically produces a normal distribution
  • D它與特徵數無關，所以必然失敗 It must fail because it is independent of the feature count
正解 B
小抄 §5 資料前處理第一面

Min-max 分母為 max-min，極端值可壓縮其餘資料。標準化也受離群值影響，不應把 StandardScaler 說成普遍抗離群值的方法。

W1-12

依監督式學習工作流程，哪個敘述正確？ Which statement follows the supervised-learning workflow?

  • A先看測試分數再決定所有資料處理 Use test scores to decide every preprocessing step
  • B選演算法後不必再評估 No evaluation is needed after choosing an algorithm
  • C訓練集分數最高就一定是最適合的模型 The highest training score always identifies the best model
  • D選擇效能指標、訓練、評估，再依結果調整設定 Choose a metric, train, evaluate, and adjust the settings

第 2 週 - PLA 與 Python 基礎

W2-1

PLA 在某一筆樣本上分類正確時，會對權重做什麼？ When the PLA classifies a sample correctly, what does it do to the weights?

  • A完全不更新 It does not update them at all
  • B往正確方向小幅更新 It updates them slightly in the right direction
  • C更新量減半 It halves the size of the update
  • D把該筆樣本移出訓練集 It removes that sample from the training set
正解 A
小抄 §2 三個線性分類器的比較第一面

感知器學習規則是「猜對不動，猜錯才更新」：w←w+ηyxw \leftarrow w + \eta y xw←w+ηyx、b←b+ηyb \leftarrow b + \eta yb←b+ηy 只在分類錯誤時執行。

第二項是最容易誤選的，因為多數學習演算法（例如 Adaline、邏輯斯迴歸）確實每一筆都更新——它們看的是連續的誤差量而非對錯。感知器只看對錯，猜對時誤差為零，自然沒有更新量。

考的觀念：只看對錯的模型，答對就沒有訊號可學。

W2-2

Novikoff 收斂定理保證 PLA 在有限步內收斂，前提是什麼？ Novikoff’s convergence theorem guarantees the PLA converges in a finite number of steps. On what premise?

  • A學習率必須夠小 The learning rate must be small enough
  • B特徵必須先標準化 The features must be standardized first
  • C訓練資料必須線性可分 The training data must be linearly separable
  • D樣本數必須大於特徵數 The number of samples must exceed the number of features
正解 C
小抄 §2 三個線性分類器的比較第一面

只要存在一個超平面能把兩類完全分開，PLA 就保證在有限步內找到一組完全分類正確的 w\boldsymbol{w}w 與 bbb。

第一項是常見的混淆：學習率影響的是收斂速度與路徑，不是收斂與否——感知器的更新方向只由分錯的樣本決定，η\etaη 只縮放步長。標準化（第二項）同樣有助於訓練，但不是定理的前提。

考的觀念：收斂保證來自資料的可分性，不是超參數的設定。

W2-3

Adaline 把感知器的階梯函數換成連續線性輸出，最關鍵的好處是什麼？ Adaline replaces the perceptron’s step function with a continuous linear output. What is the key benefit?

  • A輸出值被限制在 [0,1][0,1][0,1] 之間 The output value is confined to [0,1][0,1][0,1]
  • B損失函數變得可微分，能用梯度下降訓練 The loss becomes differentiable, so gradient descent can train it
  • C可以直接處理多元分類 It can handle multi-class classification directly
  • D不再需要設定學習率 A learning rate no longer has to be set
正解 B
小抄 §2 三個線性分類器的比較第一面

階梯函數不可微分，損失對權重的梯度無從算起，只能用「猜錯才修正」這種規則式更新。換成連續線性輸出後，均方誤差成為可微的碗狀曲面，標準梯度下降就能派上用場，訓練也從「有沒有錯」升級成「錯了多少」。

第一項描述的是 sigmoid 的性質，Adaline 的線性輸出並沒有上下界。第四項剛好相反：改用梯度下降之後，學習率反而成為關鍵超參數。

考的觀念：可微分是梯度下降的入場券。

W2-4

在 wTx+b=0\boldsymbol{w}^T\boldsymbol{x} + b = 0wTx+b=0 這個超平面中，w\boldsymbol{w}w 與 bbb 各決定什麼？ In the hyperplane wTx+b=0\boldsymbol{w}^T\boldsymbol{x} + b = 0wTx+b=0, what does each of w\boldsymbol{w}w and bbb determine?

  • Aw\boldsymbol{w}w 決定位置，bbb 決定方向 w\boldsymbol{w}w sets the position, bbb sets the orientation
  • B兩者共同決定方向，位置由資料決定 Together they set the orientation; the data sets the position
  • Cw\boldsymbol{w}w 決定維度，bbb 決定傾斜程度 w\boldsymbol{w}w sets the dimension, bbb sets the degree of tilt
  • Dw\boldsymbol{w}w 決定法向量方向，bbb 決定離原點多遠 w\boldsymbol{w}w sets the direction of the normal vector, bbb how far it sits from the origin
正解 D
小抄 §2 三個線性分類器的比較第一面

w\boldsymbol{w}w 是超平面的法向量，決定它的朝向；bbb 則把這個平面平移，決定它離原點的距離。二維特徵空間裡，w\boldsymbol{w}w 決定直線的斜率，bbb 決定截距。

第一項把兩者對調。少了 bbb 的模型會被迫讓決策邊界通過原點，表達能力因此受限——這正是偏差項不能省的理由。

考的觀念：法向量定方向，偏差項定位置。

W2-5

One-versus-All（OvA）怎麼把二元分類器推廣到多元分類？ How does One-versus-All (OvA) extend a binary classifier to multi-class classification?

  • A每個類別各訓練一個二元分類器，取信心最高者 Train one binary classifier per class and take the most confident one
  • B每兩個類別訓練一個分類器，最後投票 Train one classifier for every pair of classes and vote at the end
  • C訓練一個分類器，輸出層改成多個神經元 Train one classifier and give its output layer several neurons
  • D把多個類別合併成兩個大類後再細分 Merge the classes into two large groups, then subdivide
正解 A
小抄 §2 三個線性分類器的比較第一面

OvA 為每一個類別訓練一個「這類 vs 其餘」的二元分類器，預測時把樣本丟給全部分類器，取信心最高的那個作為答案。

第二項描述的是 One-versus-One，是另一種常見策略，分類器數量是 (k2)\binom{k}{2}(2k​) 而非 kkk 個。scikit-learn 多數分類器預設就以 OvA 支援多類別。

考的觀念：OvA 的分類器數量等於類別數。

W2-6

自適應學習率 ηt=η01+αt\eta_t = \dfrac{\eta_0}{1 + \alpha t}ηt​=1+αtη0​​ 的用意是什麼？ What is the point of the adaptive learning rate ηt=η01+αt\eta_t = \dfrac{\eta_0}{1 + \alpha t}ηt​=1+αtη0​​?

  • A讓學習率隨損失下降而自動上升 It makes the learning rate rise automatically as the loss falls
  • B避免模型過擬合訓練資料 It stops the model from overfitting the training data
  • C前期步伐大快速接近，後期步伐小穩定收斂 Large steps approach quickly early on, small steps settle stably later
  • D讓每個權重各自擁有不同的學習率 It gives every weight a learning rate of its own
正解 C
小抄 §4 梯度下降家族第一面

ttt 是 epoch 數，分母隨訓練進行而變大，學習率因此單調遞減：前期用大步伐快速逼近最低點附近，後期縮小步伐避免在谷底來回震盪。

第四項描述的是 AdaGrad、Adam 這類「每個參數各自調整」的最佳化器，與這裡單純隨時間衰減的排程不同。第二項也不對：學習率排程處理的是最佳化，不是泛化。

考的觀念：這是隨時間衰減的排程，不是隨參數調整的最佳化器。

W2-7

選用 Python 的 list、tuple、dict、set 時，主要看哪三個問題？ When choosing between Python’s list, tuple, dict and set, which three questions matter most?

  • A要不要排序、要不要去重、要不要轉型 Whether to sort, whether to deduplicate, whether to cast types
  • B要不要改、要不要順序、要不要查得快 Whether it must change, whether order matters, whether lookup must be fast
  • C資料量多大、型別是否一致、會不會跨執行緒 How large the data is, whether types are uniform, whether threads are involved
  • D要不要巢狀、要不要序列化、要不要比較大小 Whether to nest, whether to serialize, whether to compare sizes
正解 B
小抄 §14 Python 基礎第二面

可不可變（list 可變、tuple 不可變）、有沒有順序（list 與 tuple 有，dict 與 set 無序地存放）、查詢快不快（dict 與 set 用雜湊，成員查詢接近常數時間）——這三個問題就足以選定容器。

第一項的「要不要去重」只對應到 set 這一個特性，涵蓋不了另外三種。

考的觀念：用可變性、順序性、查詢成本三個軸來分類。

小抄 §12 混淆矩陣與指標第二面

第一項把值域範圍當成理由——值域寬不等於不易被誤導。第三項剛好講反：MCC 正是因為沒有忽略多數類才可靠。第二項也不對，MCC 與 F1 一樣是綁在某一個決策門檻上的指標，不受門檻影響的是 ROC AUC。

考的觀念：一個指標可不可靠，看它用了四格中的哪幾格。

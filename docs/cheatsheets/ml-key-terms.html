機器學習實作系列｜關鍵定義總表

期中範圍第 1–7 週，共 118 個名詞（第 1 週、第 2 週、第 3 週、第 5 週、第 6 週、第 7 週）。整理自各週筆記的「關鍵定義」，考前複習用。

第 1 週：機器學習簡介

名詞定義
Model（模型）學習資料規律的數學公式或演算法結構，即訓練要找出的那個函式
Sample（樣本）資料集中的一筆觀測紀錄，對應表格的一橫列
Feature（特徵）描述樣本的屬性或維度，對應表格的一直欄，也稱輸入或自變數
Target / Label / Ground truth（目標／標籤／真實答案）模型要預測的答案；Label 指資料集附帶的標籤，Ground truth 強調它是「真實」答案
Supervised learning（監督式學習）訓練資料同時含輸入與標籤，模型學「輸入 → 標籤」的對應關係
Unsupervised learning（非監督式學習）訓練資料沒有標籤，模型直接從資料結構找規律
Semi-supervised learning（半監督學習）少量標籤資料加大量無標籤資料一起訓練，兼顧準確度與成本
Reinforcement learning（強化式學習）代理人透過與環境互動、試錯，依獎勵學習能讓總獎勵最大化的策略
Classification（分類）標籤是離散類別的監督式學習任務
Regression（迴歸）標籤是連續數值的監督式學習任務
Clustering（聚類／分群）把相似資料點自動分成幾個群組的非監督式學習任務
Dimensionality Reduction（降維）把高維度資料壓縮成更精簡表示，同時盡量保留重要結構
Feature scaling（特徵縮放）訓練前把不同量級的特徵拉到同一尺度，避免數值範圍大的特徵主導模型
Feature selection（特徵選取）v.s. Feature extraction（特徵提取）選取是從原始特徵挑子集（欄位不變）；提取是組合轉換成新特徵（欄位本身改變）
Trainable parameters（可訓練參數）v.s. Hyperparameters（超參數）前者訓練中自動從資料學出；後者訓練前由人手動設定
Epoch訓練資料完整跑過一輪
Loss function（損失函數）衡量模型預測值與 ground truth 差距的函數，數值越小代表越準
Activation function（激活函數）神經元線性運算後套用的非線性函數，讓網路能表達非線性關係
Gradient descent（梯度下降）v.s. SGD（隨機梯度下降）前者每次用全部樣本算梯度；後者每次只用一筆樣本估計梯度、更新更快
Backpropagation（反向傳播）用連鎖律從輸出層往輸入層逐層計算 loss 對每個參數梯度的演算法
Overfitting（過擬合，high variance）模型過度擬合訓練資料細節，訓練集表現好但驗證／測試集表現明顯變差
Underfitting（欠擬合，high bias）模型太簡單，連訓練資料本身的規律都學不好
Regularization（正則化）在 loss function 加入懲罰項，限制參數權重不要過大以抑制模型複雜度
No Free Lunch 定理不存在一個分類器能在所有場景下都表現最好，因此要比較多種演算法

第 2 週：PLA 與 Python 基礎

名詞定義
Perceptron（感知器）1958 年 Rosenblatt 提出的最早監督式學習分類器，算出加權總和後用階梯函數輸出二元類別
Net input（淨輸入）zzzz=wTx+bz=\boldsymbol{w}^T\boldsymbol{x}+bz=wTx+b，特徵向量與權重向量的內積加偏差項
Step function（階梯函數）z≥0z\geq0z≥0 輸出 1、否則輸出 0 的判斷函數，是最原始的 activation function，不可微分
Hyperplane（超平面）wTx+b=0\boldsymbol{w}^T\boldsymbol{x}+b=0wTx+b=0 定義的決策邊界；二維特徵空間裡就是一條直線
Weights w\boldsymbol{w}w ／ bias bbb（權重／偏差項）可訓練參數；w\boldsymbol{w}w 決定超平面的法向量方向，bbb 決定它離原點多遠
PLA 更新規則分類錯誤時 w←w+ηyxw\leftarrow w+\eta y xw←w+ηyx、b←b+ηyb\leftarrow b+\eta yb←b+ηy；分類正確則不更新
Novikoff 收斂定理只要訓練資料線性可分，PLA 保證能在有限步內找到完全分類正確的 w\boldsymbol{w}w、bbb
Linearly separable（線性可分）存在一個超平面能把兩類樣本完全分開
One-versus-All（OvA，又稱 One-versus-Rest）多元分類延伸：每個類別各訓練一個二元分類器，預測時取信心最高者
Matrix transpose（矩陣轉置）把矩陣的列變行、行變列，記為上標 T；wT\boldsymbol{w}^TwT 把行向量轉成列向量以做內積
Adaline把感知器的階梯輸出換成連續線性輸出，改用均方誤差（MSE）當 loss function，可用標準梯度下降訓練
SGD（隨機梯度下降）每次只用一筆樣本估計梯度並立即更新，屬於隨機近似（stochastic approximation）
Data leakage（資料洩漏）讓測試集的統計資訊（例如平均值、標準差）提早滲進訓練流程的錯誤
Adaptive learning rate（自適應學習率）隨 epoch 遞增而遞減的學習率，ηt=η01+αt\eta_t=\frac{\eta_0}{1+\alpha t}ηt​=1+αtη0​​，前期步伐大、後期步伐小
List／Tuple／Dict／Set（列表／元組／字典／集合）Python 四種內建容器；依「要不要改、要不要順序、要不要查得快」三個問題選用
__init__ ／ self__init__ 是建構子，物件建立時自動呼叫；self 代表呼叫這個方法的物件實例本身

第 3 週：Adaline 與 NumPy、Pandas

名詞定義
自適應線性神經元（Adaline）保留感知器的淨輸入，但用連續的線性激活輸出計算均方誤差，讓模型能以梯度下降訓練的二元分類器
淨輸入（net input）特徵與權重的內積加上偏差項，z=wTx+bz=\boldsymbol{w}^T\boldsymbol{x}+bz=wTx+b
線性激活函數（linear activation function）Adaline 訓練時使用的恆等函數 σ(z)=z\sigma(z)=zσ(z)=z；它保留連續誤差，與最終分類用的閾值函數角色不同
均方誤差（Mean Squared Error, MSE）將每筆樣本的真實值與線性激活輸出之差平方後取平均；對 Adaline 而言是可微分的凸損失函數
梯度（gradient）多元函數對各參數的偏微分所組成的向量，指向函數值上升最快的方向；負梯度則指向下降最快的方向
學習率（learning rate）控制每次參數更新步幅的超參數；太大可能跨過最低點而發散，太小則收斂緩慢
全批次梯度下降（full-batch GD）每次使用全部訓練樣本計算梯度，再更新一次參數；方向穩定，但大型資料集的單步成本較高
隨機梯度下降（SGD）每看一筆樣本就估計梯度並立即更新參數；更新頻繁、路徑較吵雜，且能支援線上學習
Mini-batch 梯度下降每次用一小批樣本估計梯度，是 full-batch GD 與 SGD 的折衷，兼顧向量化效率與訓練穩定性
線上學習（online learning）模型不重新初始化權重，隨新資料到達持續更新；AdalineSGD.partial_fit() 就是本週的實作例子
特徵縮放（feature scaling）把不同特徵調整到相近數值尺度，避免大數值特徵主導運算，並讓梯度下降更穩定
標準化（standardization）每個特徵減去自身平均值再除以自身標準差，使平均值為 0、標準差為 1，但不會把資料變成常態分布
多維陣列（ndarray）NumPy 的固定型別多維陣列；元素連續儲存並帶有 shape、ndim、dtype 等資訊，適合大量數值運算
向量化（vectorization）把逐筆 Python 迴圈改寫成對整個陣列的運算，由預先編譯的底層常式一次處理資料
聚合（aggregation）用 sum、mean、std 等運算把一個維度的多個值壓縮成較少的統計值；axis 表示被壓縮的維度
廣播（broadcasting）NumPy 從最右邊維度開始比較形狀；每一對維度必須相等或其中一方為 1，才能在不實際複製資料的情況下延展運算
布林遮罩（boolean masking）以逐元素比較產生布林陣列，再用該陣列篩出符合條件的元素或資料列
花式索引（fancy indexing）把索引陣列放入中括號，一次取出任意位置；輸出形狀由索引陣列決定
np.newaxis在索引時插入一個長度為 1 的新軸，常用來調整形狀、刻意觸發廣播
序列（Series）Pandas 中帶有明確索引標籤的一維資料結構，可由 list、dict、ndarray 或純量建立
資料框（DataFrame）多個共用同一索引、彼此對齊的 Series 所組成的二維表格，可容納不同型別與缺失值
.loc ／ .iloc.loc 依標籤選取且切片包含尾端；.iloc 依整數位置選取且切片不包含尾端
缺失值（missing data）Pandas 以 NaN 或 None 表示缺少資料，常用 isnull()、dropna()、fillna() 檢查、刪除或補值
分組運算（groupby）依鍵值把資料切成多組、對各組套用運算，再把結果合併，亦即 split–apply–combine
拼接（concat）v.s. 合併（merge／join）concat 沿指定軸把資料疊起來；merge／join 則依共同鍵值配對資料列

第 5 週：邏輯迴歸、Matplotlib 與 Seaborn

名詞定義容易混淆的地方
條件機率已知特徵 x\boldsymbol{x}x 時屬於正類的機率 p(y=1∣x)p(y=1\mid\boldsymbol{x})p(y=1∣x)不是模型預測一定正確的機率
勝算p1−p\frac{p}{1-p}1−pp​，比較發生與不發生的相對可能性機率 0.8 對應勝算 4，不是 0.8
對數勝算ln⁡ ⁣(p1−p)\ln\!\left(\frac{p}{1-p}\right)ln(1−pp​)，把 (0,1)(0,1)(0,1) 映射到整條實數線邏輯迴歸線性建模的是 logit，不是直接建模 ppp
sigmoidlogit 的反函數，把任意實數 zzz 映射到 (0,1)(0,1)(0,1)它不會讓線性決策邊界自動變成非線性
概似固定資料後，衡量某組參數讓這些標籤出現有多合理概似是參數的函數，不是把參數當隨機事件的機率

資料洩漏訓練時使用了本來不該知道的測試資料資訊用測試集自己的平均值與標準差也是洩漏

第 6 週：Scikit-learn 機器學習

名詞定義
廣義資料前處理從原始資料到模型訓練之間的六個階段：資料清理、資料編碼、特徵衍生、特徵縮放、降維；其中特徵衍生與降維屬於特徵工程
資料洩漏（data leakage）訓練過程中無意間讓模型取得了測試集的資訊；最典型的成因是在切分之前就對整份資料 fit 轉換器
泛化誤差（generalization error）模型在未見過的資料上的預測誤差；測試集越小，對它的估計越不準
順序型特徵（ordinal feature）類別之間有大小順序的特徵，例如 T 恤尺寸 XL > L > M；可依領域知識映射成整數
名義型特徵（nominal feature）類別之間沒有順序的特徵，例如顏色；編成 0/1/2 會讓模型誤讀出不存在的大小關係
獨熱編碼（one-hot encoding）為名義型特徵的每個相異值建立一個 0/1 虛擬欄位；代價是欄位膨脹且彼此完全相關
多重共線性（multi-collinearity）特徵之間高度相關；對需要矩陣求逆的方法會使矩陣病態而難以求逆
正規化（normalization）min-max 縮放的特例，把特徵壓到 [0,1][0,1][0,1]；單一極端離群值就能把其餘資料擠進極小的子區間
標準化（standardization）把特徵轉成平均 0、標準差 1；保留離群值資訊，對梯度下降類的最佳化較實用
特徵選取（feature selection）從原始特徵中挑一個子集，保留原本的物理意義
特徵提取（feature extraction）從特徵集推導資訊、建構新的特徵子空間，新特徵是算出來的
序列後向選取（SBS）貪婪的特徵選取法，從全集開始，每次剔除使判準函數 JJJ 損失最小的那個特徵
貪婪搜尋（greedy search）在每一階段做局部最優選擇的演算法；通常得到次佳解，但避開了窮舉的組合爆炸
過擬合（overfitting）抓住訓練資料的規律卻無法泛化；表現為高變異，變異衡量的是一致性
欠擬合（underfitting）模型不夠複雜，連訓練資料的規律都抓不到；表現為高偏差，偏差衡量的是系統性誤差
L2L_2L2​ 正則化在損失外加上權重平方和的懲罰，又稱權重衰減；把權重一起壓小，但很少壓成零
L1L_1L1​ 正則化在損失外加上權重絕對值和的懲罰；常產生稀疏解，可直接當作特徵選取
正則化參數 λ\lambdaλ控制正則化強度；λ\lambdaλ 越大懲罰越重、越趨向欠擬合。scikit-learn 用與之成反比的 C 表示
Transformer APIscikit-learn 中負責資料轉換的介面，方法鏈為 fit() → transform()
Estimator APIscikit-learn 中負責預測的介面，方法鏈為 fit() → predict()
管線（pipeline）把多個轉換器與最後一個估計器串成單一物件的元估計器；讓「只用訓練資料 fit」成為結構上的保證

第 7 週：資料前處理與模型評估

名詞定義
超參數調整（hyperparameter tuning）狹義的模型選擇：對指定的演算法，選出調校參數的最佳值
演算法選擇（algorithm selection）廣義的模型選擇：比較不同演算法各自的最佳表現，選出最好的那個
保留法交叉驗證（holdout CV）把資料切成訓練、驗證、測試三份；缺點是結果對「訓練與驗證怎麼分」很敏感
kkk 折交叉驗證（k-fold CV）把訓練資料隨機不放回切成 kkk 折，輪流以 1 折驗證、k−1k-1k−1 折訓練，取 kkk 次的平均
分層 kkk 折（stratified k-fold）每一折中保持類別標籤的比例；分類問題應優先使用
留一交叉驗證（leave-one-out CV）kkk 等於訓練樣本數的極端情形
學習曲線（learning curve）訓練與驗證分數對訓練資料量的曲線；用來判斷再蒐集更多資料有沒有用
驗證曲線（validation curve）訓練與驗證分數對某個超參數值的曲線；用來挑該超參數
格狀搜尋（grid search）窮舉所有超參數組合；只要最佳解在網格內就保證找得到，但成本隨網格大小急遽上升
隨機搜尋（randomized search）從分布或離散集合抽樣固定次數；同樣預算下能探索更廣的取值範圍
逐次減半搜尋（successive halving）先用少量資源評估所有候選，反覆淘汰並把資源集中到存活者
巢狀交叉驗證（nested CV）外層切訓練／測試折、內層在訓練折上選模型；用於演算法選擇的不偏估計
混淆矩陣（confusion matrix）記錄 TP／TN／FP／FN 四種預測計數的方陣；所有分類指標的共同來源
真陽率 TPR（true positive rate）真實為陽性的樣本中被正確判為陽性的比例；等同召回率
偽陽率 FPR（false positive rate）真實為陰性的樣本中被誤判為陽性的比例
精確率（precision）判為陽性的樣本中真的是陽性的比例
召回率（recall）真實陽性中被抓出來的比例
F1 分數精確率與召回率的調和平均；只有兩者都高才會高
馬修斯相關係數（MCC）同時使用四格數字的相關係數，值域 [−1,1][-1,1][−1,1]；類別不平衡時比 F1 更不易被單邊表現誤導
ROC 曲線移動決策門檻所畫出的 FPR 對 TPR 軌跡；量的是排序能力而非單一門檻的表現
ROC AUCROC 曲線下面積，範圍 [0,1][0,1][0,1]；完美為 1，隨機猜測為 0.5
微平均（micro-average）每個樣本等權，由樣本數多的類別主導
宏平均（macro-average）每個類別等權，適合類別不平衡的情形
類別不平衡（class imbalance）一或多個類別在資料集中被過度代表；正確率此時會嚴重誤導

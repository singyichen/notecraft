題庫範圍與表述需留意的地方

  • W5-11（transAxes）、W5-12（Seaborn／Matplotlib 分工）出自第5週筆記的延伸預習；筆記明說該堂課未講標註與 Seaborn。本次為了補齊92題而加入，不代表老師已講過或一定會考。
  • W7-10：固定機率分數降低門檻時 recall 不減，但 precision 不保證下降。題庫預期 B 是常見趨勢，並非無條件定理。
  • W1-11／W6-8：依課堂比較可選標準化，但 z-score 的平均與標準差也會受離群值影響，不能視為真正穩健縮放。
  • W2-7 詳解稱 dict 無序：現代 Python 的 dict 保留插入順序；這不影響該題正解 B。W2-11 詳解稱 tuple 都可雜湊也不夠精確，需元素皆可雜湊。
  • W5-15：平方誤差 16 正確；但「把邊界往錯方向拉」不是所有資料下都成立。小抄保留可以驗算的「z 被拉回標籤 1」，不把它寫成通用幾何結論。
  • W5-16：「多標籤只能 OvR」太絕對；題目選項中 A 合理，但其他多標籤方法也存在。
  • W6-2：核 SVM 預測成本也受支援向量數影響，並非永遠便宜。W6-7：0/1 欄通常不必再縮放是課堂慣例，是否標準化仍依模型與需求。
  • W6-10：較大模型理論訓練 loss 不高於較小模型，需要可表達函式集合包含、目標可比等條件；該題用於提醒先排查最佳化。

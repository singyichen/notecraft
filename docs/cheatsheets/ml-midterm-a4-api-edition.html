2三個線性分類器的比較

感知器 PLAAdaline邏輯迴歸
淨輸入$z=\boldsymbol w^T\boldsymbol x+b$（三者相同）
激活階梯函數 step（不可微）恆等 $\sigma(z)=z$sigmoid $\frac{1}{1+e^{-z}}$
損失依誤分類更新MSE（凸）二元交叉熵 BCE（log loss、負對數概似）
更新時機只有分錯才更新依連續誤差更新（分對也可能更新）同 Adaline
輸出0／1線性值；0/1 標籤門檻 0.5機率 $p(y{=}1|\boldsymbol x)$
  • 決策邊界為超平面hyperplane；PLA／Logistic：$z=0$；本課 Adaline 門檻 .5：$z=.5$。原始閾值與 bias：$b=-\theta$
  • PLA（0/1 標籤）：$\Delta w=\eta(y-\hat y)x$、$\Delta b=\eta(y-\hat y)$；分對不更新。Novikoff：線性可分linearly separable保證有限步收斂；不可分需設 epoch 上限
  • Adaline 從「對或錯」改成「差多少」→ 可微分 → 能用梯度下降
  • 邏輯迴歸更新式和 Adaline 形式相同：$\boldsymbol w\leftarrow\boldsymbol w+\eta\frac1n\boldsymbol X^T(\boldsymbol y-\boldsymbol a)$，差在 $a$ 是 sigmoid 輸出
  • 多元分類：OvR／OvA（$K$ 個二元分類器；互斥多類取最高分，多標籤各自切門檻，機率不必加總為 1）vs softmax（類別互斥，機率和＝1）

3邏輯迴歸細節

  • 名字有 regression，做的是分類；線性建模的是 logit，不是 $p$
  • 勝算 $\frac{p}{1-p}$（$p{=}0.8$ → 4）；logit $=\ln\frac{p}{1-p}$ 把 $(0,1)$ 映到全實數。為什麼要繞這圈：線性式 $\boldsymbol w^T\boldsymbol x+b$ 的值域是整條實數線、機率卻只在 $(0,1)$，所以改成「用線性式建模 logit」，再用其反函數 sigmoid 轉回機率，$\sigma(0)=0.5$
  • sigmoid 輸出是條件機率 $p(y{=}1|\boldsymbol x)$＝「已知特徵時屬於正類」的機率，不是預測正確的機率
  • BCE：$L=-\frac1n\sum[y\ln a+(1-y)\ln(1-a)]$；單筆 $y{=}1$ 時 $-\ln a$，自信地答錯（$a\to0$）損失 $\to\infty$
  • 損失辨識：Adaline 的 MSE 比較 $y$ 與線性輸出 $z$；邏輯迴歸的 BCE 比較 $y$ 與機率 $a=\sigma(z)$，不要把 $z$ 當機率。Adaline：$y=1,z=5$ 已分對，平方誤差仍為 16，會把 $z$ 拉回 1
  • 決策邊界 $z=0$ 仍是線性（sigmoid 不會讓邊界變彎）；要非線性得做特徵工程（如 $|x_1|$ 表達離 0 多遠、$x^2$）
  • sklearn：predict_proba 給機率、C 越小正則化越強

4梯度下降家族

每次更新用特性
Full-batch GD全部樣本方向穩、每步貴；每輪更新 1 次
SGD1 筆更新頻繁、路徑吵雜、可線上學習（partial_fit），每 epoch 要洗牌
Mini-batch一小批 $B$折衷，可向量化；每輪 $\lceil n/B\rceil$ 次（留末批）→ $n{=}100,B{=}20$ 是 5 次
  • 更新：$\boldsymbol w\leftarrow\boldsymbol w-\eta\nabla L$（沿負梯度，梯度指向上升最快）
  • 學習率太大 → 跨過谷底、loss 上升發散；太小 → 收斂很慢
  • 自適應學習率 $\eta_t=\frac{\eta_0}{1+\alpha t}$：前期大步、後期小步
  • 特徵縮放feature scaling讓等高線接近圓、GD 收斂快很多；標準化只平移縮放，分布形狀不變≠變成常態分布

5資料前處理

  • 前處理項目：清理、編碼、特徵衍生、縮放、降維（衍生、降維屬特徵工程）
  • 黃金法則：先切分、再處理；轉換器只對訓練集 fit，測試集只 transform
  • 資料洩漏data leakage：測試集資訊（平均、標準差…）滲進訓練 → 分數虛高
  • 缺值：isnull().sum() 數每欄；刪 dropna() 或補（平均、最頻繁值＝類別型、KNN）；空字串 "" 不算缺值
  • 順序型ordinal（XL>L>M）→ 手動映射整數；名義型nominal（顏色）→ 獨熱編碼one-hot，編 0/1/2 會造出假的大小關係
  • 獨熱 $k$ 類：含截距的線性模型可丟一欄剩 $k-1$ 欄，避免完全共線（全 $k$ 欄和為 1，與截距相依）；不是所有模型都必須丟欄
  • 特徵 X 與標籤 y 分清楚：名義特徵可 one-hot；一般分類標籤只要一致對應，整數編號無大小意義。
  • 課堂：one-hot 的 0/1 欄通常不必另縮放；不是所有應用都禁止縮放。
  • 切分比例依資料量；分類用 stratify=y
正規化 min-max標準化 z-score
公式$\frac{x-x_{\min}}{x_{\max}-x_{\min}}$ → $[0,1]$$\frac{x-\mu}{\sigma}$ → 平均 0、標準差 1
離群值敏感（其餘被擠扁）仍受離群值影響；不限制範圍
類別MinMaxScalerStandardScaler（離群多用 RobustScaler）

標準化有助 GD／SGD，但仍受離群值影響。Min-max 訓練範圍 [0,1]，新資料可超出；抗極值可考慮 RobustScaler。

6過擬合／欠擬合與正則化

過擬合欠擬合
別名高變異 high variance高偏差 high bias
症狀訓練好、驗證差（有縫）訓練、驗證都差
對策加資料、加強正則化、減特徵、降複雜度加特徵、更複雜模型、減弱正則化
$L_2$（權重衰減）$L_1$
懲罰$\frac{\lambda}{2n}\sum w_j^2$$\frac{\lambda}{n}\sum |w_j|$
效果全部壓小、很少變 0稀疏，很多權重恰為 0 → 可當特徵選取
幾何約束區域是圓菱形，角在座標軸上
  • $\lambda$ 越大越趨向欠擬合；sklearn 的 $C\propto 1/\lambda$：C 越小 = 正則化越強
  • 正則化前通常先標準化（各特徵尺度一致，懲罰才公平）
  • 較大模型訓練 loss 反而更高：先查最佳化（初始化、學習率），不能只判過擬合。
  • 泛化誤差＝在沒見過的資料上的誤差，用測試集估計；測試集越小估得越不準

7特徵選取

  • 序列特徵選取＝貪婪搜尋greedy search：每一步只挑當下最好的一欄，前面丟掉的之後不再回頭考慮，所以是次佳解；但避開了窮舉 $2^d$ 組合的爆炸
  • SFS 從空集合逐個加入；SBS 從全集逐個剔除使判準 $J$ 損失最小者
  • $L_1$＋SelectFromModel：$L_1$ 會把不重要的權重壓到恰好 0，等於順手做了選取

9易混淆一句話

① 邏輯迴歸損失 = 交叉熵，不是 MSE（MSE 是 Adaline）　② 感知器分對不更新　③ 不可線性分 → PLA 不收斂　④ 標準化 ≠ 常態化　⑤ 對測試集 fit = 洩漏　⑥ 訓練分數本身就低 ≠ 過擬合　⑦ C 是正則化強度的倒數　⑧ $L_1$ 稀疏、$L_2$ 只壓小　⑨ 本課 One-hot 的 0/1 欄通常不另縮放　⑩ 多標籤可用 OvR，softmax 給互斥多類　⑪ $\boldsymbol w$ 定超平面方向（法向量）、$b$ 定離原點遠近 → 只改 $b$ 是平移邊界　⑫ 激活函數的用途是引入非線性；Adaline 訓練用恆等函數算誤差，分類時仍用閾值　⑬ 概似是參數的函數，不是參數的機率　⑭ 變異＝換份資料結果差多少（一致性）、偏差＝系統性誤差　⑮ 多重共線性 → 需要矩陣求逆的方法會病態　⑯ 獨熱的代價：欄位膨脹、與截距完全共線

11模型選擇與交叉驗證 model selection / CV

  • 狹義：超參數調整hyperparameter tuning；廣義：演算法選擇algorithm selection（用巢狀 CV）
  • Holdout：訓練／驗證／測試三份；缺點是結果對切法敏感
  • k 折k-fold：輪流 1 折驗證、$k-1$ 折訓練，取 $k$ 次平均（看平均＋標準差）；常用 $k{=}10$；資料少可取較大 k，多則較小以省計算
  • 分層 k 折stratified：每折保持類別比例 → 分類優先；LOOCV：$k=n$（資料很少時）
  • 巢狀 CVnested CV：外層評估、內層挑超參數；例 $5\times2$
  • 選好超參數後，用完整訓練集重訓；測試集最後評估一次，不用來挑選
曲線橫軸回答
學習曲線 learning curve訓練資料量多蒐集資料有沒有用
驗證曲線 validation curve某超參數值該選多少（驗證分數峰值）
  • 兩線都低且貼合 → 高偏差，只加資料通常幫助有限
  • 訓練高、驗證低、中間有縫 → 高變異，加資料可能改善
  • 若橫軸向右代表能力增加（如 C↑），train升、CV降 → 過擬合；λ↑時方向相反
搜尋做法取捨
Grid 格狀窮舉組合網格內保證找到；次數 $k\times\prod n_j$
Random 隨機從分布抽固定次數重要參數常只有少數；同預算探索更廣
Halving 逐次減半少資源全評估、逐輪淘汰節省資源；可能早淘汰好候選

12混淆矩陣與指標 confusion matrix

預測陽預測陰
真實陽 $P$TPFN（漏報）
真實陰 $N$FP（誤報）TN
  • $\text{ACC}=\frac{TP+TN}{\text{全部}}$，$\text{ERR}=1-\text{ACC}$
  • $\text{PRE}=\frac{TP}{TP+FP}$：「說是陽的有幾成真陽」
  • $\text{REC}=\text{TPR}=\frac{TP}{TP+FN}$：「真陽抓到幾成」
  • $\text{FPR}=\frac{FP}{FP+TN}$；$\text{F1}=\frac{2\,PRE\cdot REC}{PRE+REC}$（調和平均，兩者都高才高）
  • MCC 用四格，$[-1,1]$，不平衡時比 F1 穩
  • ROC：掃門檻畫 FPR(x)–TPR(y)；AUC 1 完美、0.5 瞎猜；量排序能力
  • 常見取捨：門檻低 → recall↑、precision↓；嚴格說 recall 不減，precision 不保證下降；癌症篩檢重 recall，垃圾信過濾重 precision
  • 微平均micro每樣本等權（大類主導）；宏平均macro每類別等權（不平衡適用）
  • 挑出某一格的樣本：mask=(y_true==1)&(y_pred==0) → np.where(mask)[0] 即 FN 的索引；陣列條件用 &／| 且各加括號
  • 類別不平衡class imbalance：1% 陽性全猜陰也有 99% ACC → 改指標、過採樣、加權 class_weight

例：TP40 FN10 FP20 TN30 → ACC .70、PRE .667、REC .80、F1 .727、FPR .40

廣播broadcasting：從最右邊維度往左比，每對須相等或其一為 1；缺的維度補 1；結果取各維最大。

形狀結果
(4,3)+(3,)(4,3)　右邊左補成 (1,3)；3=3、1 撐成 4
(4,3)+(4,)ValueError
　補成 (1,4) 後最右 3 vs 4，兩者都不是 1 → 失敗。要成功先 reshape(-1,1)
(4,1)+(3,)(4,3)　(4,1) 與 (1,3)，兩邊各把 1 撐開
(3,1,2)−(5,2)(3,5,2)　2=2、1 撐成 5、左補 1 給 3（座標差，還不是距離）
(8,1,6,1)+(7,1,5)(8,7,6,5)　右邊補成 (1,7,1,5)，逐位取大
(n,)+(n,1)(n,n)：不報錯卻算錯！
　(n,) 補成 (1,n) 被當成一「列」、另一個是直欄，撐成方陣
  • axis=k 表示被壓掉的那一維——axis 寫幾，shape 的第幾個數字就消失（標準化的 X.mean(axis=0) 就是「每個特徵欄各一個平均」）；.T 對一維陣列無效（只有一個軸，沒有兩軸可換），要直欄得用 reshape(-1,1) 或 np.newaxis
  • 距離矩陣distance matrix：A:(a,m)、B:(b,m) → A[:,None,:]-B[None,:,:]，即 (a,1,m) 與 (1,b,m) 廣播成 (a,b,m)＝每對點的座標差；再沿 axis=2 取 norm 壓掉 m 才是 (a,b) 距離
  • 同步洗牌shuffle：idx=rng.permutation(len(y))、X,y=X[idx],y[idx] 必須用同一組索引
  • b=a 只是多一個名字指向同一塊資料，改 b 等於改 a；b=a.copy() 才另配一份。np.where(cond,1,0) 是三參數版：條件成立取 1、否則取 0，逐元素套用
  • ndarray 元素同型別；切片可能不連續；向量化由預編譯底層常式處理，減少 Python 迴圈；矩陣乘法用 @
  • 線上學習online learning：課堂 AdalineSGD.partial_fit 保留原權重，用新資料接續更新；fit 重新初始化訓練。

18模型內部功能辨識

各片段獨立辨識，對照課堂 0/1 分類；np 為 NumPy。

z = X @ w + b
# 淨輸入；X:(n,d), w:(d,) → z:(n,)
y_hat = (z >= 0).astype(int)
# PLA 的階梯分類：z=0 也輸出 1
pred = int(xi @ w + b >= 0)
update = eta * (target - pred)
w += update * xi; b += update
# PLA 單筆更新：分對 → update=0
a = z
# Adaline 訓練用線性激活
a = 1 / (1 + np.exp(-z))
# 邏輯迴歸 sigmoid；不是類別標籤
errors = y - a
w += eta * X.T @ errors / len(y)
# 全批次更新；a 的定義決定模型
b += eta * errors.mean()
程式／線索辨識重點
((y-a)**2).mean()MSE；Adaline 的 a 是線性輸出
出現 y*np.log(a)BCE；a 是機率
外層 epoch、內層逐筆更新若依連續誤差／梯度更新為 SGD；PLA 也有逐筆迴圈
每輪對整個 X 算梯度一次Full-batch；每輪更新 1 次
X=np.array([[1.,2.],[3.,4.]])
w=np.array([1.,-1.]); b=0.
z=X@w+b → [-1.,-1.] # X@w=[1·1+2·(−1), 3·1+4·(−1)]=[−1,−1]，再加 b
(z>=0).astype(int) → [0,0] # −1≥0 不成立；True→1、False→0
# 同一筆換 b=1.：z=[0,0]
p=1/(1+np.exp(-z)) → [.5,.5] # σ(0)=1/(1+1)=.5
pred=(p>=.5).astype(int) → [1,1] # .5≥.5 成立，邊界算正類
eta=0.1; target=1; pred=0
u=eta*(target-pred) → 0.1 # .1×(1−0)；分對時差為 0 就不更新
w+u*X[0] → [1.1,-0.8] # [1,−1]+.1×[1,2]
b+u → 0.1 # 0+.1

題目要機率就回 p、要類別才回 pred，別混用。MSE 代入例：$y{=}[1,0]$、$a{=}[.8,.3]$ → $e{=}[.2,-.3]$、$\frac{.04+.09}{2}=.065$。

更新係數別硬背，先看損失定義。Adaline 損失是 $\frac1n\sum e^2$ 時 w += eta*2*(X.T@e)/len(y)、b += eta*2*e.mean()；題目若寫 $\frac1{2n}\sum e^2$ 就少一個 2。邏輯迴歸 BCE 改成 e = y - p 且沒有那個 2。

BCE 實作：防 log(0) 的兩種等價寫法

p = np.clip(p, 1e-15, 1-1e-15)
loss = -np.mean(y*np.log(p) + (1-y)*np.log(1-p))
# @ 對一維陣列＝逐項相乘後加總，除樣本數即平均
loss = (-y @ np.log(p) - (1-y) @ np.log(1-p)) / len(y)

y 與 p 都應為 (n,)，別把閾值化後的 pred 當 p 代入。單筆 $y{=}1$：$p{=}0.9$ → $0.105$、$p{=}0.1$ → $2.303$，分對類別不代表 loss=0。迴圈：$X$、$y$ 各 4 筆、range(3) 內層逐筆 → 共 12 筆次，但 PLA 實際更新可少於 12 次；下一筆沿用前一筆更新後的參數。

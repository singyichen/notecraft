CH6　MOS 電晶體與 CS 放大器

關鍵定義

名詞定義
金氧半場效電晶體（MOSFET）以 MOS 電容控制表面反轉層濃度的四端元件；閘極、源極、汲極、基板。電流為通道中電子（NMOS）或電洞（PMOS）的漂移電流。
MOS 電容（MOS capacitor）閘極、氧化層、矽基板構成的平行板電容；Cox=εoxtoxC_{ox} = \frac{\varepsilon_{ox}}{t_{ox}}Cox​=tox​εox​​ 為每單位面積的電容，單位 F/cm2\text{F/cm}^2F/cm2。
反轉層／通道（inversion layer / channel）閘極電壓把 P 型基板表面的電洞推開、再把電子吸到氧化層界面所形成的 N 型薄層；它把源極與汲極連起來。
空乏區（depletion region）電洞被推開後留下的固定負受體離子區；形成反轉層之前的中間階段，也是體效應的來源。
臨界電壓（threshold voltage，VTHV_{TH}VTH​）讓反轉層剛好成形所需的閘極–源極電壓；投影片給典型值 300300300–500 mV500\ \text{mV}500 mV。
過驅動電壓（overdrive voltage）VGS−VTHV_{GS}-V_{TH}VGS​−VTH​；真正用來產生通道電荷的那一部分電壓，所有電流與轉導公式的核心變數。
源極與汲極（source / drain）理想基本結構中的兩個同型重摻雜區，可依偏壓互換；NMOS 通常以電位較低者為源極。實際元件不一定完全對稱。
寬長比（aspect ratio，WL\frac{W}{L}LW​）設計者唯一可以自由選擇的幾何自由度；ID∝WLI_D \propto \frac{W}{L}ID​∝LW​，但閘極電容 ∝WL\propto W L∝WL。
夾止（pinch-off）汲極端的閘極–通道電位差降到 VTHV_{TH}VTH​ 以下、反轉層在該端消失；元件仍導通，電子由夾止區的強電場掃入汲極。
三極管區（triode region）先滿足 VGS>VTHV_{GS}>V_{TH}VGS​>VTH​，再有 VDS<VGS−VTHV_{DS} < V_{GS}-V_{TH}VDS​<VGS​−VTH​（等價於 VGD>VTHV_{GD} > V_{TH}VGD​>VTH​）；通道完整，元件像一顆電壓控制電阻。
深三極管區（deep triode region）VDS≪2(VGS−VTH)V_{DS} \ll 2(V_{GS}-V_{TH})VDS​≪2(VGS​−VTH​)；電流與 VDSV_{DS}VDS​ 成正比，元件就是阻值 RonR_{on}Ron​ 的線性電阻，用於電子開關。
飽和區（saturation region）先滿足 VGS>VTHV_{GS}>V_{TH}VGS​>VTH​，再有 VDS≥VGS−VTHV_{DS} \ge V_{GS}-V_{TH}VDS​≥VGS​−VTH​（等價於 VGD≤VTHV_{GD}\le V_{TH}VGD​≤VTH​）；等號為剛好夾止。放大器要用的區域，與 BJT 的「飽和區」意思相反。
平方律（square-law）飽和區電流與過驅動電壓的平方成正比；相對於 BJT 的指數關係弱得多，這是 MOS 轉導較小的根源。
製程轉導參數（μnCox\mu_n C_{ox}μn​Cox​）遷移率乘上單位面積閘極電容，單位 A/V2\text{A/V}^2A/V2，由製程決定；題目通常直接給定。
轉導（transconductance，gmg_mgm​）飽和區電流對 VGSV_{GS}VGS​ 的偏導數；三種等價寫法見下節公式，分別在「固定寬長比」「固定過驅動電壓」「固定電流」三種題型好用。
通道長度調變（channel-length modulation）汲極電壓升高使夾止點往源極移動、有效通道變短、電流微升；以因子 (1+λVDS)(1+\lambda V_{DS})(1+λVDS​) 表示，對應 BJT 的爾利效應。
通道長度調變係數（λ\lambdaλ）單位 V−1\text{V}^{-1}V−1；短通道通常較大、長通道通常較小，但也受製程與偏壓影響。設計者可透過 LLL 改變其趨勢。
輸出電阻（output resistance，ror_oro​）ro≈1λIDr_o \approx \frac{1}{\lambda I_D}ro​≈λID​1​；通道長度調變在小訊號模型中的表現，與負載並聯而限制增益。
本質增益（intrinsic gain）gmro=2λ(VGS−VTH)g_m r_o = \frac{2}{\lambda(V_{GS}-V_{TH})}gm​ro​=λ(VGS​−VTH​)2​；單顆元件能提供的最大電壓增益，與偏壓電流無關。
體效應（body effect）NMOS 的 VSBV_{SB}VSB​ 增加時，源極–本體接面反偏加大、空乏區變厚，臨界電壓上升；是否顯著取決於本體與源極的實際連接。
二極體連接元件（diode-connected device）閘極與汲極短接的 MOS；看進去的電阻為 1gm∥ro≈1gm\frac{1}{g_m}\parallel r_o \approx \frac{1}{g_m}gm​1​∥ro​≈gm​1​，當負載時增益只由兩個寬長比的比值決定。
PMOS 電晶體極性全部反轉的 MOS：N 型基板、p+p^+p+ 源汲極、電洞導電、需負的閘源電壓；μp<μn\mu_p < \mu_nμp​<μn​，同尺寸電流較小；小訊號模型與 NMOS 完全相同。
CMOS 技術在 P 型基板上挖 N 型井放置 PMOS，使兩種極性的元件共存於同一片晶圓；今日數位與多數類比 IC 的基礎。
本體／基板（body / bulk）MOS 的第四隻腳；NMOS 接最低電位、PMOS 接最高電位，確保源汲極與基板的接面保持逆偏。

CH8　運算放大器

關鍵定義

名詞定義
運算放大器（operational amplifier，op amp）兩個輸入、一個輸出的電路，放大的是兩個輸入的差：Vout=A0(Vin1−Vin2)V_{out}=A_0(V_{in1}-V_{in2})Vout​=A0​(Vin1​−Vin2​)。

閉迴路（closed-loop）輸出經電阻接回輸入之後的狀態；閉迴路增益由外部電阻決定，不再是 A0A_0A0​。
非反相端（noninverting input）把負輸入接地後，Vout=+A0Vin1V_{out}=+A_0V_{in1}Vout​=+A0​Vin1​ 的那一端；符號上的「＋」記的是斜率為正，與電源極性無關。

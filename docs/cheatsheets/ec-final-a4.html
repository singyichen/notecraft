1解題程序（精簡）

MOS：假設飽和 → 算 $I_D$ → $V_{DS}=V_{DD}-I_DR_D$ → 驗 $V_{GD}\lt V_{TH}$；不成立改用三極管式重算。
運放：虛短路 $V_+=V_-$＋輸入不吃電流 → 負端 KCL。
回授：認出 $A_0$（斷開回授的增益）與 $K$ → 先算 $1+KA_0$，增益、阻抗、頻寬都是它的乘除。

3MOS 電流式

  • 三極管：$I_D=\frac12\mu_nC_{ox}\frac WL\left[2(V_{GS}-V_{TH})V_{DS}-V_{DS}^2\right]$
  • 飽和：$I_D=\frac12\mu_nC_{ox}\frac WL(V_{GS}-V_{TH})^2$ 6-6
  • 含通道長度調變：$\times(1+\lambda V_{DS})$
  • 峰值：$V_{DS}=V_{GS}-V_{TH}$ 時 $I_{D,max}=\frac12\mu_nC_{ox}\frac WL(V_{GS}-V_{TH})^2$
  • 導通電阻（$V_{DS}\ll2(V_{GS}-V_{TH})$）：
    $R_{on}=\dfrac{1}{\mu_nC_{ox}\frac WL(V_{GS}-V_{TH})}$
  • PMOS（講義 p.34）有號：$\frac12\mu_pC_{ox}\frac WL(V_{GS}-V_{TH})^2(1-\lambda V_{DS})$
    絕對值：$\frac12\mu_pC_{ox}\frac WL(|V_{GS}|-|V_{TH}|)^2(1+\lambda|V_{DS}|)$
  • 體效應（$V_{SB}=V_S-V_B\gt0$）：
    $V_{TH}=V_{TH0}+\gamma\left(\sqrt{2\phi_F+V_{SB}}-\sqrt{2\phi_F}\right)$
  • $C_{ox}=\dfrac{\varepsilon_{ox}}{t_{ox}}$
  • 兩點求 $V_{TH}$（Lab 3）：$\sqrt{I_D}$ 對 $V_{GS}$ 是直線
    $\dfrac{\sqrt{I_{D2}}}{\sqrt{I_{D1}}}=\dfrac{V_{GS2}-V_{TH}}{V_{GS1}-V_{TH}}$，再回代求 $\mu_nC_{ox}\frac WL$

3′單位與換算

  • $\mu\text{A/V}^2\times\text{V}^2=\mu$A；$\text{mA/V}\times\text{k}\Omega$＝無因次；$\mu\text{A}\times\text{k}\Omega=$ mV

5小訊號參數

  • 轉導三式：
    $g_m=\mu_nC_{ox}\frac WL(V_{GS}-V_{TH})=\sqrt{2\mu_nC_{ox}\frac WLI_D}=\dfrac{2I_D}{V_{GS}-V_{TH}}$
  • 輸出電阻 $r_o\approx\dfrac{1}{\lambda I_D}$

10加法與減法（Lab 5）

  • 反相加法（$R_3$ 回授）：$V_{out}=-\left(\dfrac{R_3}{R_1}V_{in1}+\dfrac{R_3}{R_2}V_{in2}\right)$；權重 $R_k=\frac{R_f}{w_k}$

12閉迴路基本式

  • $Y=A_1(X-X_F)$、$X_F=KY$ → $H=\dfrac YX=\dfrac{A_1}{1+KA_1}$
  • 回授因子 $K=\dfrac{X_F}{Y}$；迴路增益 $KA_1$
  • 誤差 $E=X-X_F=\dfrac{X}{1+KA_1}$
  • $KA_1\gg1$：$H\approx\dfrac1K$
  • 量迴路增益：輸入接地、斷開迴路、注入 $V_{test}$：$KA_1=-\dfrac{V_N}{V_{test}}$ 12-3
  • 靈敏度：$\dfrac{\Delta H}{H}\approx\dfrac{1}{1+KA_1}\cdot\dfrac{\Delta A_1}{A_1}$

22Bode 與振盪條件

  • 每個極點：幅度 $-20$ dB/dec；相位 $0.1\omega_p$ 開始降、$\omega_p$ 處 $-45°$、$10\omega_p$ 處約 $-90°$ 12-34
  • 閉迴路 $\dfrac{H(s)}{1+KH(s)}$；$KH(j\omega_1)=-1$ 時發散
  • Barkhausen：$|KH(j\omega_1)|=1$ 且 $\angle KH(j\omega_1)=-180°$
  • $\omega_{GX}$：$|KH|=1$；$\omega_{PX}$：$\angle KH=-180°$
  • 穩定：$\omega_{GX}\lt\omega_{PX}$（即 $|KH(\omega_{PX})|\lt1$）
  • $\text{PM}=180°+\angle KH(\omega_{GX})$；$0°$ 振盪、約 $45°$ 臨界、$\gt60°$ 穩定
  • 單、雙極點不會振盪：相位到 $\omega=\infty$ 才 $-180°$ 12-36

23三級 CS、$K=1$ 12-38

  • 三重極點 $\omega_p=\dfrac{1}{R_DC_1}$；$|H|=\dfrac{(g_mR_D)^3}{\left[1+(\omega/\omega_p)^2\right]^{3/2}}$
  • 每級 $-60°$ → $\omega_{PX}=\sqrt3\,\omega_p$（$\tan60°=\sqrt3$）
  • $|H(\omega_{PX})|=\dfrac{(g_mR_D)^3}{2^3}\lt1$ → $g_mR_D\lt2$

24頻率補償 12-42・12-43

  • 把主極點往低頻移 → $\omega_{GX}$ 左移、$\omega_{PX}$ 不動 → PM 變大
  • 步驟：$-180°+\text{PM}$ 對應的頻率即新 $\omega_{GX}$；從那點以 $+20$ dB/dec 往左上畫到低頻增益，交點就是新主極點 $\omega_p'$
  • 極點相距遠、PM $=45°$：新 $\omega_{GX}$＝第二極點 $\omega_{p2}$ → $\omega_p'=\dfrac{\omega_{p2}}{KA_0}$
  • 米勒補償：$C_{eq}=\left[1+g_{m5}(r_{O5}\parallel r_{O6})\right]C_c$

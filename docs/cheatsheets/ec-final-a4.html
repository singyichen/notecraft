1MOS 的起點是電容，不是接面

  • 閘極／氧化層／基板＝平行板電容，$C_{ox}=\varepsilon_{ox}/t_{ox}$（每單位面積，$\text{F/cm}^2$）。氧化層越薄 → $C_{ox}$ 越大 → 同樣電壓存更多電荷 → 電流越大
  • 通道形成兩階段：先空乏（電洞被推開，留下固定負受體離子）再反轉（電子被吸到界面形成 N 型薄層）
  • 「反轉」只是偏壓下的表面狀態，摻雜本身沒變，撤掉電壓就恢復
  • $V_{TH}$＝反轉層剛好成形所需的 $V_{GS}$，典型 $300\text{–}500\ \text{mV}$
  • 過驅動電壓 $V_{GS}-V_{TH}$：$V_{TH}$ 以下那段是入場費，不產生任何可導電的電子
  • 源汲極由偏壓決定（NMOS 電位低者為源極），不是製程決定
  • 本體（第四隻腳）NMOS 接最低電位、PMOS 接最高電位 → 讓寄生 PN 接面保持逆偏（為安全，不是為性能）

2工作區判準（兩步，別跳）

區條件（NMOS）
截止$V_{GS}\le V_{TH}$
三極管導通後 $V_{DS}\lt V_{GS}-V_{TH}$（等價 $V_{GD}>V_{TH}$）
深三極管$V_{DS}\ll 2(V_{GS}-V_{TH})$ → 線性電阻
飽和導通後 $V_{DS}\ge V_{GS}-V_{TH}$（等價 $V_{GD}\le V_{TH}$）
陷阱：$V_{GS}>V_{TH}$ 只決定導不導通，不決定在哪一區。先比 $V_{GS}$ 與 $V_{TH}$，再比 $V_{DS}$ 與過驅動電壓。
陷阱：MOS 的「飽和區」＝可放大的區域，和 BJT 的「飽和區」意思相反（BJT 飽和＝不能放大）。

3電流與轉導

  • 三極管：$I_D=\frac12\mu_nC_{ox}\frac{W}{L}\left[2(V_{GS}-V_{TH})V_{DS}-V_{DS}^2\right]$
  • 飽和：$I_D=\frac12\mu_nC_{ox}\frac{W}{L}(V_{GS}-V_{TH})^2(1+\lambda V_{DS})$
  • 深三極管丟掉二次項 → $R_{on}=\dfrac{1}{\mu_nC_{ox}\frac{W}{L}(V_{GS}-V_{TH})}$（$V_{GS}$ 越高電阻越小）
  • 開關衰減 $\dfrac{V_{out}}{V_{in}}=\dfrac{R_{ant}}{R_{ant}+R_{on}}$
  • 通道電荷 $Q=WC_{ox}(V_{GS}-V_{TH})$；沿途 $Q(x)=WC_{ox}[V_{GS}-V(x)-V_{TH}]$，$Q$ 歸零處＝夾止
  • $I=Q\cdot v$ 的 $Q$ 是每單位長度電荷（$\text{C/m}$），因次：$\text{C/m}\times\text{m/s}=\text{A}$
  • 轉導三式（等價，挑「固定什麼」用）：
    $g_m=\mu_nC_{ox}\frac{W}{L}(V_{GS}-V_{TH})=\sqrt{2\mu_nC_{ox}\frac{W}{L}I_D}=\dfrac{2I_D}{V_{GS}-V_{TH}}$
陷阱：固定 $I_D$ 時 $g_m$ 與過驅動電壓成反比（要加大 $W/L$）；沒固定電流時才是正比。選錯式子答案相反。

4通道長度調變・輸出電阻・本質增益

  • $V_{DS}$ 升高 → 夾止點往源極移 → 有效通道變短 → 電流微升；因子 $(1+\lambda V_{DS})$，$\lambda$ 單位 $\text{V}^{-1}$
  • 對應 BJT 的爾利效應（Early effect）
  • $r_o\approx\dfrac{1}{\lambda I_D}$（與 $I_D$ 成反比）
  • 本質增益 $g_mr_o=\dfrac{2}{\lambda(V_{GS}-V_{TH})}$ → 與偏壓電流無關（$g_m\propto\sqrt{I_D}$ 升、$r_o\propto1/I_D$ 降，抵消）
  • 想降低 $\lambda$ → 加大 $L$（$W$ 無效，$W$ 只按比例縮放電流）
  • $I_D\propto W/L$，但閘極電容 $\propto WL$ → $W$ 加倍：電流加倍、電容也加倍

5體效應・小訊號・PMOS／CMOS

  • $V_{TH}=V_{TH0}+\gamma\left(\sqrt{2\varphi_F+V_{SB}}-\sqrt{2\varphi_F}\right)$，$V_{SB}=V_S-V_B$
  • $V_{SB}\uparrow$ → 空乏區變厚 → $V_{TH}\uparrow$ → 同 $V_{GS}$ 電流變小。體效應只會讓元件變難開
  • 小訊號模型＝工作點附近的一階線性化；振幅大到工作點明顯移動就失效
  • 二極體連接（閘汲短接）：$R=\frac{1}{g_m}\parallel r_o\approx\frac{1}{g_m}$
  • PMOS：$\mu_p\lt\mu_n$ → 同尺寸電流較小（常畫寬 2–3 倍補償）；小訊號模型與 NMOS 完全相同
  • CMOS：P 型基板挖 N 型井放 PMOS，兩種極性共存於同一片晶圓
陷阱：任何「電流從閘極流進來」的敘述都是錯的——閘極隔著氧化層，直流電流為零。

8運放與四個理想條件

  • 定義式 $V_{out}=A_0(V_{in1}-V_{in2})$ → 放大的是差，共模被消掉
  • 輸入端的 $\pm$ 記的是轉移特性的斜率正負，與電源極性無關（電源是另外兩隻腳）
  • $A_0$ 無因次；$60\ \text{dB}=1000$（電壓用 $20\log_{10}A$）
理想條件允許忽略失效時看到
$A_0=\infty$兩輸入的電位差增益誤差 $G/A_0$
$R_{in}=\infty$輸入吸走的電流偏壓電流造成直流偏移
$R_{out}=0$負載的影響換重負載增益掉下來
$\mathrm{BW}=\infty$頻率響應與迴轉率高頻增益下滑；大訊號正弦變三角

9虛短路與虛接地

  • $V_{in1}-V_{in2}=\dfrac{V_{out}}{A_0}\to0$
  • 「電位相同」來自 $A_0=\infty$；「沒有電流」來自 $R_{in}=\infty$（兩條規則來源不同，常被拆開考）
  • 成立前提：負回授＋輸出沒飽和。回授接到「＋」端 → 正回授 → 輸出貼軌、虛短路失效
  • 虛短路是電路的性質，不是元件的性質；是零階近似，不是等式
  • 虛接地＝電位被釘在 0 V，但沒有實體接地線（真接地的話電路就不成立）

10基本組態

電路增益$R_{in}$
非反相$1+\dfrac{R_1}{R_2}$（$R_2$＝接地那顆）極高
反相$-\dfrac{R_1}{R_2}$$=R_2$
單位增益$\dfrac{A_0}{1+A_0}\approx1$極高
反相加法器$-\sum_k\dfrac{R_f}{R_k}V_k$各路 $R_k$
  • 同組電阻下非反相比反相的增益大 1（訊號有一條不經放大的直通路徑）
  • 非反相增益下限是 1，做不出小於 1
  • 單位增益放大器改變的是阻抗不是電壓（緩衝器：電壓不變，電流改由運放供應）
  • 反相加法＝電流在虛接地點相加，各路互不影響；同相加法器是「先分壓再放大回來」，兩路會互相負載
陷阱：反相組態的 $R_{in}$ 是 $R_2$，不是運放的無限輸入阻抗 → 高阻抗訊號源會被分壓拉垮，要先加緩衝器。

11增益誤差與擺幅

  • $\text{gain error}=\dfrac{G}{A_0}$，$G=1+\dfrac{R_1}{R_2}$。只看比值，與電阻絕對值無關；反相與非反相的誤差項相同
  • $G$ 越大誤差越大 → 增益 100 拆成兩級各 10：$10\%\to$ 約 $2\%$
  • 擺幅 $V_{EE}\lt V_{out}\lt V_{CC}$；超出＝削平（正常物理限制，不是接錯）
  • 單電源（$V_{EE}=0$）：交流訊號要先抬到約 $V_{CC}/2$
  • 削平＝頂部平；迴轉率不足＝正弦變三角。兩者不同
  • 「運算」來自外部元件：電阻→加減、電容在回授→積分、電容在輸入→微分
電子學實作｜期末小抄（二）CH12 回授・跨章主軸整章只有一條式子 $H=\frac{A_1}{1+KA_1}$，其餘都是它的變形

12回授的骨架

  • 前饋系統 $A_1$（主要增益）、回授因數 $K=X_F/Y$
  • 閉迴路 $H=\dfrac{A_1}{1+KA_1}\xrightarrow[KA_1\gg1]{}\dfrac{1}{K}$
  • 迴路增益 $KA_1$＝繞一圈的增益，與切點無關；量法：切開迴路注入 $V_{test}$，$KA_1=-\dfrac{V_N}{V_{test}}$
  • 比較誤差 $E=\dfrac{X}{1+KA_1}$ → 這就是 CH8 虛短路的真正來源
  • 三個量別混：$H$（使用者關心）、$A_1$（元件性質）、$KA_1$（決定一切好處與代價）

13同一個 $1+KA_1$ 的五種面貌

量變化
增益$\div(1+KA_1)$
頻寬$\times(1+KA_0)$
靈敏度 $\frac{\mathrm d\ln H}{\mathrm d\ln A_1}$$=\dfrac{1}{1+KA_1}$
比較誤差$\div(1+KA_1)$
阻抗$\times$ 或 $\div(1+KA_0)$，見 §15
  • 增益頻寬乘積 $A_0\omega_0$ 守恆：回授只能重新分配，不能增加（那是前饋系統的性質）
  • 靈敏度例：$KA_1=99$、$A_1$ 變 2 倍（$100\%$）→ $H$ 只變約 $1\%$
  • 好處與代價等價交換，不能只拿一邊

14線性化（失真下降）

  • 轉移曲線分段，各段局部增益 $\dfrac{A_i}{1+KA_i}\to\dfrac{1}{K}$ → 原本差很多的斜率被壓成一樣 → 曲線被拉直
  • 和增益去敏感化是同一現象的兩種說法
陷阱：不是「回授網路濾掉諧波」，也不是「振幅變小所以沒進非線性區」。

15四種放大器與理想阻抗

放大器$R_{in}$$R_{out}$
電壓（V→V）$\infty$$0$
電流（I→I）$0$$\infty$
轉阻（I→V）$0$$0$
轉導（V→I）$\infty$$\infty$

唯一規則：不要干擾被量／被送的量。讀電壓就要高阻抗（不吸電流），讀電流就要低阻抗。

16回授組態與阻抗變化

  • 選法：輸出要什麼就感測什麼；輸入是什麼就回送什麼
  • 感測電壓 → 並聯在輸出端取樣；感測電流 → 串聯進輸出迴路。都不能干擾被量的量
  • 電壓–電壓：$R_{in}\to R_{in}(1+KA_0)$、$R_{out}\to\dfrac{R_{out}}{1+KA_0}$
  • 電壓–電流（轉阻）：$\dfrac{V_{out}}{I_{in}}=\dfrac{R_0}{1+KR_0}$，$R_{in}\to\dfrac{R_{in}}{1+KR_0}$、$R_{out}\to\dfrac{R_{out}}{1+KR_0}$（兩端同向）
  • 方向不必背：回授把電路推向它所模仿的那個理想放大器（倍率相同，方向由理想目標決定）
注意：Razavi 的「電壓–電流」是輸出–輸入順序，與 Sedra/Smith 的「串聯–並聯」（輸入–輸出）相反；投影片自己註明此命名非標準。

17穩定性

  • Barkhausen（振盪條件，兩條同時成立）：$\lvert KH(j\omega_1)\rvert=1$ 且 $\angle KH(j\omega_1)=-180°$，等價於 $KH(j\omega_1)=-1$（閉迴路分母為零）
  • $\omega_{GX}$ 增益交越：$\lvert KH\rvert=1$（$0\ \text{dB}$）
  • $\omega_{PX}$ 相位交越：$\angle KH=-180°$
  • 安全：$\omega_{GX}\lt\omega_{PX}$（增益先掉到 1）；不穩定：$\omega_{PX}\lt\omega_{GX}$
  • $\mathrm{PM}=\angle H(\omega_{GX})+180°$
  • PM 不只決定穩不穩，還決定過衝與安定時間：PM 小 → 振鈴久；PM 大 → 不過衝但慢。實務目標約 $60°$
  • 單極點系統永遠穩定（相位最多 $-90°$，到不了 $-180°$），不論迴路增益多大
  • $K$ 變大（回授變強）→ $\lvert KH\rvert$ 整條上移 → $\omega_{GX}$ 右移 → PM 變小、更難穩定（$K=1$ 最難，故規格書標 unity-gain stable）
  • 三級相同共源、$K=1$：穩定條件 $g_mR_D\lt 2$ → 增益上限低到沒有實用價值，所以多級非補償不可
陷阱：「誤差被壓小」≠「系統變穩」。$1+KA_1$ 越大，靜態精度越好但動態越容易振盪——兩者是對立的。

18補償

  • 主極點補償：把某一個極點刻意壓到很低，讓增益從那裡單調以 $-20\ \text{dB/dec}$ 下滑，在遇到第二個極點前就掉到 $0\ \text{dB}$ → 系統在 $\omega_{GX}$ 之前「看起來像單極點」。代價是頻寬大減
  • 米勒補償：$C_{eq}=\left[1+g_{m5}(r_{O5}\parallel r_{O6})\right]C_c$，方括號＝跨接那一級的增益加 1。用小電容換大等效值，省晶片面積（電容按面積計價）
  • μA741 上肉眼可見的大電容＝內建補償電容，確保連 $K=1$ 都穩定，代價是 GBW 只有約 $1\ \text{MHz}$

20三章其實是同一個故事

  • CH6：算出一顆元件的參數（$g_m$、$r_o$），而它們隨製程跑 $\pm20\%$
  • CH8：用回授把增益換成兩顆電阻的比值（比值準得多）
  • CH12：說明這筆交換的匯率是 $1+KA_1$，以及它的代價
  • $1/K$ 之所以可靠：同片晶圓相鄰元件的比值可做到 $1\%$ 內，即使絕對值一起跑掉比值不變

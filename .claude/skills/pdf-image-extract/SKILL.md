# PDF Image Extract Skill

從 PDF 講義萃取圖片、放進已經用「逐頁名詞詳解」格式整理過的 NoteCraft 筆記。核心風險不是「萃取不到圖」，而是**漏掉某一頁該有的圖卻沒人發現**——所以流程刻意設計成「每一頁都要被歸類」，而不是「盡量多截幾張」。

## 何時使用

- 筆記已經依 PDF 內容逐頁整理成文字（例如電子學系列的「教材精讀」），現在要把對應的圖也放進去
- 作者指出某一頁的圖漏掉了、要求重新檢查有沒有遺漏
- 拿到一份新的課程 PDF，要把裡面值得保留的圖萃取出來備用

## 何時不使用

- 作者要的是把 PDF 文字內容整理成筆記（那是一般讀 PDF 寫筆記；可以先做那個，再回頭用這個 skill 補圖）
- PDF 是純文字投影片，掃過目錄就知道沒有值得保留的圖

## 前置需求

```bash
pip3 install pymupdf
```

## 工作流程

### 1. 逐頁萃取，不要用「感覺重要的頁」手動挑

用 `scripts/extract_all.py` 對整份 PDF 跑一次：

```bash
python3 .claude/skills/pdf-image-extract/scripts/extract_all.py \
  "<PDF 路徑>" <暫存輸出資料夾，例如 scratchpad/pdf-images/xxx> \
  --min-size 80 --dpi 150
```

腳本邏輯（這是不遺漏的關鍵）：

- 每一頁先抓**內嵌點陣圖**（`page.get_images`），過濾掉短邊小於 `--min-size` 的裝飾圖示（公司 Logo、頁碼浮水印）
- **若該頁完全沒有內嵌點陣圖**（常見於用向量線條手繪的電路圖、曲線圖、公式推導），自動退回**整頁截圖**（`--dpi` 控制解析度）當 fallback，確保每一頁都至少有一張圖可用
- 輸出 `manifest.json`，逐頁列出抓到的檔名、尺寸、`type`（`embedded` / `fullpage-fallback`）——**這份清單的頁碼集合就是後面核對遺漏的基準**，長度必為 PDF 總頁數

跑完先看終端機印出的 `pages=N embedded_images=X fullpage_fallbacks=Y`，確認 `X+Y ≥ N`（每頁至少一張）。

### 2. 逐頁人工判斷，不要整批塞進筆記

用 Read 工具開 manifest 裡的候選圖（可以先用 `python3 -c "import json; ..."` 或直接讀 `manifest.json` 列出清單再逐一開檔），對每一頁的每張圖做決定：

- **有教學價值**（歷史照片、電路圖、公式圖表、實驗波形、專利圖）→ 保留，準備嵌入
- **裝飾用**（標題文字渲染、單純 Logo、空白頁、純背景色）→ 跳過，但記下理由
- **fullpage-fallback 但實際上頁面主要是文字**（沒有值得保留的圖形內容）→ 跳過，記下理由

**每一頁都要出現在「保留」或「跳過」其中一邊，不能因為看起來不重要就悄悄不處理。**

### 3. 依「第 X 頁」找筆記裡的插入點

筆記若已用逐頁格式整理，內文會有「第 29 頁」「（第 X 頁）」這類標註，先抓一輪全部位置：

```bash
grep -n "第 [0-9]\+\(–[0-9]\+\)\?\s*頁" <筆記路徑>
```

逐一比對步驟 2 保留下來的頁碼：

- 筆記裡有對應段落 → 用 Edit 在該段落之後插入，格式照專案既有慣例：

  ```mdx
  ![具體描述圖片內容的 alt text](/note-images/<slug>/<檔名>)

  *一句話說明這張圖在講什麼、跟正文哪個論點對應。*
  ```

  圖片先複製到 `public/note-images/<slug>/`，檔名用 `NN-描述性英文slug.ext`（`NN` 是流水號，不是頁碼——同一頁常對應筆記裡好幾個小節，跨頁的圖也可能合併成一個概念）
- 筆記完全沒提到某個保留頁 → 停下來問作者要不要新增一段文字說明再放圖，還是這張圖其實不需要進筆記
- 筆記提到某頁但該頁在步驟 2 被判斷為跳過 → 在最終報告說明原因（例如「該頁是純文字大綱，沒有可萃取的圖形」）

### 4. 三份清單核對，聯集必須等於總頁數

處理完後列出：

1. **已插入**：頁碼 → 檔名 → 插入到筆記哪個標題／段落底下
2. **判斷跳過**：頁碼 → 理由（裝飾圖示／純文字頁／與其他頁重複）
3. **仍缺漏**：頁碼 → 為什麼沒放（找不到對應段落、需要作者確認、萃取品質不足）

**這三份清單的頁碼聯集要等於 PDF 總頁數；少一頁沒被歸類，代表漏檢查，要回頭補上，不能交差。** 跟作者回報時三份都要列出來，不要只報「已插入」那份。

### 5. 驗證

```bash
npx astro build 2>&1 | tail -20
```

確認新增的 `<img>` 都能正常建置；圖片較多時建議抽查 2–3 張確認檔案本身沒有截錯區域（例如整頁截圖把旁邊段落的文字也框進去，需要的話用圖片編輯工具或改用更精確的裁切範圍重新輸出）。

## 已知限制

- `fullpage-fallback` 是整頁截圖，含標題文字與其他段落，不是乾淨裁切——遇到這種情況，接受連題目文字一起入圖，或者告知作者需要手動裁切
- 掃描版／低解析度 PDF 萃取品質有限，`--dpi` 調高也救不回原始解析度不足的問題
- 腳本只做「有沒有東西可抓」的機械判斷，**看得懂這張圖有沒有教學價值**（步驟 2）一定要人／agent 親自看過每一張，不能靠尺寸或位置自動篩選

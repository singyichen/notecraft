# 數學背景讀者的常見誤解與陷阱

## 概念類

| 誤解 | 正確理解 |
| --- | --- |
| 「電位是一個絕對值」 | 只有電位差有意義。接地（ground）是任意選的零點，像選座標原點。換零點所有電壓一起平移，電流不變。 |
| 「電洞是一種粒子」 | 電洞是記帳工具：共價鍵裡缺一顆電子的位置。鄰近電子跳過來填，空位就「移動」了。把它當作帶 $+q$ 的準粒子計算完全正確，但別問它的質量是什麼（那是有效質量 $m_p^*$，一個擬合參數）。 |
| 「電流方向 = 電子移動方向」 | 慣例電流是正電荷移動方向，電子實際反向。所有電路分析都用慣例方向，不用管電子。 |
| 「電場推、粒子就一直加速」 | 晶格碰撞是阻力，粒子達到終端速度 $v = \mu E$。這是第 3 步漂移的全部內容。 |
| 「擴散需要力」 | 擴散沒有力，純粹是隨機走動加上兩側粒子數不同的統計結果。電流看斜率 $dn/dx$，不看濃度 $n$。 |
| 「空乏區裡什麼都沒有」 | 空乏的是「可動載子」；固定離子還在，所以有淨電荷、有電場、有電位差。這正是 $V_0$ 的來源。 |
| 「$V_{BE} = 0.7\ \text{V}$ 是定律」 | 這是指數曲線太陡造成的近似：電流變 10 倍電壓只動 60 mV，所以在常用電流範圍內電壓幾乎固定。真正的關係是 $I = I_S e^{V/V_T}$。 |
| 「近似就是不嚴謹」 | 電子學的近似是漸近分析：先零階、再一階、剩餘項交給模擬器。40/40 法則是刻意的工程取捨。 |
| 「$kT$ 和 $V_T$ 是同一個東西」 | $kT$ 是能量（eV），$V_T = kT/q$ 是電壓（V）。數值都是 26 m 開頭，單位不同。 |

## 符號與慣例

| 慣例 | 說明 |
| --- | --- |
| $q$ 永遠是正數 $1.6\times10^{-19}\ \text{C}$ | 電子電荷寫成 $-q$。Razavi 全書如此。 |
| $J_n = +qD_n\,dn/dx$、$J_p = -qD_p\,dp/dx$ | 差一個負號純粹因為電荷正負，不是兩個不同定律。 |
| $E$ 既是電場也是能量的符號 | 看上下文：$E$ 單獨出現或配 $\mu E$ 是電場；$E_g$、$E/kT$ 是能量。 |
| $V_R$ 逆偏電壓 | Razavi 在 $C_j$ 公式裡 $V_R$ 取負值（逆偏為負），所以寫 $1 - V_R/V_0$。其他書可能寫 $1 + V_R/V_0$ 並取 $V_R > 0$。 |
| 電流箭頭進元件的端為正 | 被動元件（電阻、二極體）的電壓極性與電流方向遵循此慣例，功率 $P = VI > 0$ 表示吸收功率。 |

## 單位陷阱

| 陷阱 | 後果 | 對策 |
| --- | --- | --- |
| 半導體參數用 cm，SI 公式用 m | 差 $10^2$、$10^4$、$10^6$ 倍 | 整章統一用 cm：$n$ 用 cm⁻³、$\mu$ 用 cm²/(V·s)、$D$ 用 cm²/s、$E$ 用 V/cm |
| $k$ 用 J/K 但 $E_g$ 用 eV | 指數算出天文數字 | 指數裡的 $E/kT$ 兩者同用 eV：$k = 8.62\times10^{-5}\ \text{eV/K}$ |
| 忘了 $n_i$ 要平方 | $V_0$、$I_S$ 差一個對數項或 $10^{10}$ 倍 | 公式裡看到 $N_A N_D$ 就想到分母是 $n_i^2$ |
| $\ln$ 與 $\log_{10}$ | 60 mV 法則變 26 mV | $V_T \ln 10 = 60\ \text{mV}$；$V_T \ln e = 26\ \text{mV}$ |

## 讀電路圖的固定程序（第 3 章起）

1. 標出接地與所有電源，決定每個節點的已知電壓。
2. 對每個非線性元件（二極體、電晶體）假設一個狀態（on/off、飽和/線性）。
3. 用該狀態的線性模型取代元件，寫 KCL 解線性方程組。
4. 驗證假設：二極體 on 則電流必須 $> 0$；off 則電壓必須 $< V_{D,on}$。矛盾就換假設重解。
5. 需要小訊號時，在解出的工作點對每個非線性元件做一階泰勒展開。

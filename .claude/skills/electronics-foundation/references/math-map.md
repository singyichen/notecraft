# 電子學 ↔ 數學對照表

按 Razavi 章節排列。每一列都是「教材裡的說法」對「數學課已經學過的東西」。解釋概念時優先用右欄的名字。

## 第 2 章：半導體物理

| 電子學 | 數學 | 備註 |
| --- | --- | --- |
| Boltzmann 因子 $e^{-E/kT}$ | 指數分佈尾機率 | 整章所有指數的唯一來源 |
| 本質載子濃度 $n_i \propto T^{3/2} e^{-E_g/2kT}$ | 前因子 × 尾機率 | $T^{3/2}$ 是「有多少狀態可填」，指數是「多少比例被熱能填上」 |
| 質量作用定律 $np = n_i^2$ | 平衡態的不變量 | 摻雜改變 $n$ 與 $p$ 各自的值，但乘積不變 |
| 漂移 $v = \mu E$ | 有阻力的運動達到終端速度 | 像空氣阻力下的落體，$\mu$ 是「摩擦係數」的倒數 |
| 擴散 $J = qD\,\dfrac{dn}{dx}$ | Fick 定律，熱傳導方程的來源 | 隨機走動 + 濃度梯度 ⇒ 淨流。電流看斜率，不看高度 |
| Einstein 關係式 $D/\mu = kT/q$ | 布朗運動（漲落與耗散同源） | 兩種機制背後是同一組隨機碰撞，見推導鏈 |
| PN 接面平衡態 | 一階可分離變數 ODE | 「漂移 + 擴散 = 0」解出 $n(x) \propto e^{qV(x)/kT}$ |
| 內建電位 $V_0 = V_T \ln\dfrac{N_A N_D}{n_i^2}$ | 上式積分後的邊界條件 | 兩端濃度比取對數 |
| 空乏區寬度 $\propto \sqrt{V_0 + V_R}$ | Poisson 方程 $\dfrac{d^2V}{dx^2} = -\dfrac{\rho}{\varepsilon}$ 積分兩次 | 固定電荷密度 ⇒ 電場線性 ⇒ 電位二次 |
| 接面電容 $C_j = C_{j0}/\sqrt{1 - V_R/V_0}$ | 平行板電容 $C = \varepsilon A / d$，$d$ 隨電壓變 | 逆偏越大、空乏區越寬、電容越小 |
| 二極體方程式 $I = I_S(e^{V_D/V_T} - 1)$ | 障壁高度改變 ⇒ 尾機率乘上 $e^{V_D/V_T}$ | 60 mV 法則 $= V_T \ln 10$ |

## 第 3 章：二極體電路

| 電子學 | 數學 | 備註 |
| --- | --- | --- |
| 理想／定電壓模型 | 分段線性逼近 | 把指數換成「開路 or 定電壓源」兩段 |
| 判斷二極體 on/off | 分情況討論（casework） | 先假設狀態、解線性方程、驗證假設不矛盾；矛盾就換狀態 |
| KCL / KVL、節點分析 | 線性方程組 $Ax = b$ | 每個節點一條 KCL，未知數是節點電壓 |
| 負載線 | 直線與曲線的交點 | 元件的 I-V 曲線 ∩ 外部電路的直線 |
| 小訊號模型 $r_d = V_T / I_D$ | 一階泰勒展開 | 在工作點把非線性換成切線斜率 |
| 大訊號 vs 小訊號 | 全域函數 vs 局部線性化 | 小訊號分析只在偏壓點附近有效 |
| 整流、漣波 $V_r \approx \dfrac{I_L}{fC}$ | 一階 ODE 的分段解 | 電容放電段用 $I = C\,dV/dt$ 近似線性 |

## 第 4 到 7 章：BJT、MOS 與放大器

| 電子學 | 數學 | 備註 |
| --- | --- | --- |
| $I_C = I_S e^{V_{BE}/V_T}$ | 同二極體方程式 | 電晶體是「用第三端控制障壁高度的二極體」 |
| 跨導 $g_m = \partial I_C / \partial V_{BE} = I_C / V_T$ | 偏導數 | 小訊號模型的核心參數 |
| 電壓增益 $A_v = -g_m R_C$ | 鏈鎖律 | $\Delta V_{out} = -R_C \cdot g_m \cdot \Delta V_{in}$ |
| MOS 平方律 $I_D = \tfrac12 \mu_n C_{ox} \tfrac{W}{L}(V_{GS} - V_{TH})^2$ | 二次函數 | 飽和區；$g_m$ 是它的導數 |
| Early 效應、通道長度調變 | 一階修正項 $(1 + \lambda V_{DS})$ | 微擾展開 |
| 頻率響應、$-3\ \text{dB}$ 點 | 複數、$s = j\omega$、極點零點 | 電容變成 $1/(j\omega C)$，電路變成有理函數 |
| Bode 圖 | 對數座標上的漸近線 | $20\log_{10}|H|$ 對 $\log\omega$ |

| 電子學 | 數學 | 備註 |
| --- | --- | --- |
| 理想運放、虛短路 | $A \to \infty$ 的極限 | 負回授把 $V_+ - V_- \to 0$ |

## 文化差異：近似不是偷懶

數學訓練會抗拒「$V_{BE} \approx 0.7\ \text{V}$」這種寫法。電子學的做法是：

1. 先找主導項，砍掉次要項，得到封閉解（40/40 法則：接受四成誤差換四成時間）。
2. 用封閉解建立直覺，知道每個變數往哪邊推結果。
3. 需要精確時交給模擬器（Tinkercad、LTspice）。

把它理解成「先做零階與一階近似，再看剩餘項」，就是漸近分析。

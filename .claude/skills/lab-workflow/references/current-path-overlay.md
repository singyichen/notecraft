# 電流分析圖：在接線圖上疊出電流實際流動路徑

## 為什麼要第二張圖

Tinkercad 截圖只回答「接在哪」，不回答「為什麼會動」。作者是數學背景、沒修過電路學，
看著一張正確的接線圖仍然說不出電流從哪出發、經過什麼、為什麼電表讀到那個值。
所以**每張接線圖都要再產一張電流分析圖**：同一張圖疊上路徑、方向、編號與電表角色，
配一段逐步文字與估算式。原圖保留不動，兩張一起放進筆記。

一張合格的電流分析圖要能單獨回答四個問題：

1. 電流從哪出發、經過什麼、回到哪裡（閉迴路）
2. 每個元件的方向對不對（二極體陽極／陰極、電容極性、齊納色環）
3. 每台電表**串聯還是並聯**、量的是什麼
4. 預期讀數怎麼算（一條 KVL 就能驗算現場數據）

## 產出與命名

| 東西 | 位置 |
| --- | --- |
| 原始接線圖／原理圖 | `public/note-images/ec-week<N>-tinkercad/lab<L>-exp<M>-breadboard.png`、`-schematic.png` |
| 電流分析圖 | 同資料夾，原名加 `-current` 後綴 |
| 座標與標籤 | `simulations/lab<L>/annotate_current_path.py` |
| 畫法原語 | `simulations/tools/current_overlay.py`（共用，不要各週複製一份） |

**絕對不要覆蓋原圖。** 原圖是「接線長這樣」的證據，分析圖是教材，兩者在筆記裡並存。

## 流程

### 1. 先有原始圖

照 `tinkercad-recipes.md` 把電路接好、開著模擬截圖。讀值要顯示出來——分析圖最後要用
這組讀值驗算估算式。

### 2. 量座標（最花時間的一步，別用猜的）

座標一律以**原圖 1 倍尺寸**為單位，`compose()` 會負責放大與加留白。做法是裁切區域、
放大 3 倍、用 Read 打開看，讀出像素位置再除回去：

```bash
python3 -c "
from PIL import Image
im = Image.open('public/note-images/ec-week3-tinkercad/lab1-exp1-breadboard.png')
print(im.size)
im.crop((330,270,660,460)).resize((330*3,190*3), Image.LANCZOS).save('/tmp/crop.png')
"
# 再用 Read 打開 /tmp/crop.png：裁切圖座標 ÷ 3 + 裁切原點 = 原圖座標
```

麵包板先把**欄距**量出來就一勞永逸：找兩個相距已知欄數的欄位標籤，算出
`colx(n) = x1 + pitch * (n - 1)`，之後所有孔位都用 `colx()` 算；列（j/i/h/g/f）
與兩條電源軌各記一個 y 就夠。寫成常數放在腳本開頭，改版面時只動這幾個數字。

### 3. 寫 `annotate_current_path.py`

只放座標與標籤文字，畫法一律 `from current_overlay import ...`。路徑用折線點列表達，
每個轉角一個點。**方向就是點的順序**——習慣電流從電源正極出發，一路寫到回電源負極。

### 4. 跑完一定要用 Read 打開看

這是唯一會抓到錯位的步驟，不看就等於沒驗證。逐項核對：線有沒有貼著實際導線走、
箭頭方向對不對、標籤有沒有蓋住元件或彼此重疊、編號有沒有壓到要讀的欄位標籤。
發現問題改座標重跑，不要在圖上手動修。

### 5. 寫進筆記

圖不會自己說話，一定要配文字。固定四段（範例見第 3 週實驗一）：

1. 一段引言：說明綠線／紅箭頭／編號／藍虛線各代表什麼，附疊圖腳本連結
2. 兩張圖各配一句 figcaption：麵包板那張講「串聯迴路處處電流相同」，原理圖那張講
   「開放端不是斷路，是被省略的儀器」
3. 一張逐步說明表：`| 編號 | 電流走到哪 | 為什麼走這裡 |`，列數與圖上編號一致
4. 兩台電表各量什麼 + 預期讀數估算式（display math），並用圖上的實際讀值驗算一次

## 畫法規範

| 元素 | 畫法 | 原語 |
| --- | --- | --- |
| 電流路徑（原圖畫得出來的段） | 實心綠 `GREEN`，麵包板線寬 13、原理圖 14 | `path(d, pts)` |
| 電流路徑（原圖省略、要補畫的段） | 綠虛線 `GREEN_DASH`，週期 28 | `path(..., dash=True)` |
| 「這個狀態下沒有電流」的整圈 | 綠細虛線（`w=9`），照樣保留方向箭頭 | `path(..., col=GREEN_DASH, w=9, dash=True)` |
| 被擋住的元件（逆偏二極體、沒導通的那半週） | 紅叉，麵包板上 `size=14`–16、原理圖 30 左右 | `blocker()` |
| 方向 | 紅色銳角三角形，畫在每段中點 | `path()` 自動，`arrow_min` 控制門檻 |
| 步驟編號 | 紅底白字圓圈，r=22，沿路徑順序 1、2、3… | `badge()` |
| 電壓表量測線 | 藍虛線 `BLUE`，線寬 6–7，**不畫箭頭** | `path(..., col=BLUE, arrows=False)` |
| 原圖沒畫的儀器 | 白底圓圈 + Ⓐ／Ⓥ | `meter()` |
| 說明標籤 | 白底灰框，`\n` 換行，文字用該類別的顏色 | `label()` |

顏色語意固定：**綠＝電流走的路、紅＝方向與順序、藍＝只量不分流**。不要為了好看換色。

幾個實務要點：

- **某一段想多一個箭頭**：在那段中間插一個轉折點把它切成兩段。電流表／電壓表符號擺在
  一段的正中間時會蓋掉該段唯一的箭頭，這時一定要切。
- **留白當畫布**：原圖擠不下的東西（標題、側邊說明、原理圖省略的回程迴路）就放
  `pad` 加出來的留白。留白底色預設取原圖左上角，接起來沒有縫。
- **原理圖先裁切再放大**：Tinkercad 線路圖檢視匯出的圖很小（幾百 px），直接放大字會糊。
  用 `crop=` 只留有內容的區域，`scale=4` 以上再畫。
- **中文字級**：Heiti TC 沒有粗體字重，`stroke_width` 會讓密集筆畫（壓、體、幾）糊成一團。
  要更重就加大字級，不要加 stroke；數字例外（筆畫簡單，`bold=True` 沒問題）。
- **標題一律 `label(d, (W // 2, 26), ..., align="center")`**，不要自己減一個猜出來的寬度。
- **Heiti TC 沒有 `✕`**，標籤文字寫「紅叉」，圖上的叉用 `blocker()` 畫。

## 一定要標到的六件事

- [ ] 閉迴路：從電源正極到負極連續不中斷，沒有斷點
- [ ] 每段的方向箭頭
- [ ] 依序編號，且與筆記表格的列一一對應
- [ ] 每台電表的接法（串聯畫在路徑上、並聯畫成藍虛線）與它量的量
- [ ] 有方向性的元件：二極體陽極／陰極在第幾欄、色環端朝哪、齊納是逆偏
- [ ] 原圖省略的東西（線路圖檢視不畫儀器造成的開放端）用虛線補回去並說明

## 交流電路（實驗三、四這類）怎麼處理

電流方向會隨半週改變，**一張圖畫不完就拆成多張**，不要在同一張圖上用第二種顏色畫第二條
路徑——顏色語意一旦多一個就全毀了。同一張底圖輸出多張時，用後綴區分：

| 狀態 | 檔名後綴 |
| --- | --- |
| 導通／正半週（預設） | `-current` |
| 不導通／負半週 | `-neg-current` |
| 濾波電容充電 | `-charge-current` |
| 濾波電容放電 | `-discharge-current` |

- **半波整流**：正半週（綠粗線）與負半週（整圈細虛線 + 紅叉）各一張。兩張擺在一起才說得出
  「一個週期只有一半的時間有電流」，也才對得上示波器上山丘與平線的兩段。
- **橋式整流**：正負半週各一張，導通的兩顆畫綠線、另兩顆打紅叉。重點是**負載那一段兩張的
  箭頭方向一樣**——這正是全波整流的意義，筆記要配一張正負半週的對照表。
- **有濾波電容**：充電那張要畫出「電流在輸出節點分成兩路」（一路餵負載、一路充電容）；
  放電那張只剩電容與負載之間的區域迴路，電源那一圈改成細虛線並在二極體上打紅叉。
  兩張都畫完才說得清楚漣波是怎麼來的（$\tau = RC$ 對上半週期）。
- **逆偏／截止的狀態不要畫成「斷路」**：路還在，只是電流小到看不見。整圈用細虛線＋紅叉，
  比留白更能說明「電流表讀 0 不是沒接好」。

## 常見錯誤

| 現象 | 原因與做法 |
| --- | --- |
| 綠線沒貼著導線、偏一整排孔 | 欄距是用兩個相鄰欄量的，誤差會累積。改用相距 4 欄以上的兩點算 pitch |
| 路徑在電表處斷掉 | 電流表的兩支探棒要分成「進去」與「出來」兩條路徑，中間補一小段虛線表示穿過表內 |
| 電壓表被畫成迴路的一部分 | 電壓表不分流，只能是藍虛線、沒有箭頭。畫成綠線等於告訴讀者它串在迴路裡 |
| 某段沒有箭頭 | 該段比 `arrow_min` 短，或箭頭被儀器符號／編號圓圈蓋住（兩者都畫在中點）。插轉折點把該段切成兩段，或把編號挪開中點 |
| 編號圓圈壓住要看的元件 | 電阻、電容本體都比圓圈小。把編號移到相鄰的空列（麵包板 f、g 列）或元件右側兩三欄 |
| 標籤壓住要讀的欄位標籤／元件 | 移到留白區或元件之間的空列（麵包板的 g、f 列通常是空的） |
| 圖產完直接貼進筆記 | 沒用 Read 打開看就是沒驗證。錯位、重疊、方向相反都只有看圖才會發現 |
| 原圖被覆蓋 | 輸出一律加 `-current` 後綴；接線圖與分析圖在筆記裡並存 |
| 估算式和圖上讀值對不起來 | 固定壓降模型（$V_{D,on}=0.7$ V）在導通電壓附近會失效，要改用圖上的實際 $V_D$ 代入 $(V_s-V_D)/R$，並在筆記點破模型的適用範圍 |

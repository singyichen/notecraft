# CircuitJS（falstad.com/circuit）電路文字檔格式與連結產生

## 產生連結

1. 把電路寫成純文字檔 `simulations/<lab>/circuitjs/<id>.txt`（格式見下）。
2. `node .claude/skills/lab-workflow/scripts/circuitjs-link.mjs simulations/<lab>/circuitjs/*.txt` 印出每個檔案的 `?ctz=` 連結（`lz-string` 壓縮，與官方「Export as URL」相同）。
3. 加 `--check --out <dir>` 會用本機 Chrome 開每個連結截圖，**一定要看截圖**確認元件有畫出來、示波器有波形、沒有錯誤對話框，再把連結貼進筆記。
4. 筆記附錄同時保留文字檔內容（`檔案 → 從文字匯入` 的備援）。

## 檔案格式（每行一個元件，座標以 16 px 為格，元件端點對齊格點）

```text
$ 1 0.000005 10.20027730826997 50 5 43 5e-11
```
選項列：旗標 1（顯示電流黃點）、最大時間步 5 µs、模擬速度、電流速度、**電壓範圍（±V，示波器與導線顏色的刻度，輸入 ±10 V 就改 10）**、功率亮度、最小時間步。

| 元件 | 語法 | 備註 |
| --- | --- | --- |
| 導線 | `w x1 y1 x2 y2 0` | 只有端點重合才算連接，穿過另一條線的中間不會連 |
| 接地 | `g x y x y2 0 0` | |
| 電阻 | `r x1 y1 x2 y2 0 <Ω>` | |
| 電容 | `c x1 y1 x2 y2 0 <F> 0` | 第三個數是初始電壓 |
| 二極體 | `d x1 y1 x2 y2 2 default` | **點 1 是陽極、點 2 是陰極**；`default` 模型膝點約 0.5 V |
| 齊納 | `z x1 y1 x2 y2 0 <Vz>` | 旗標 0 時第六欄是崩潰電壓 |
| 電壓源 | `v x1 y1 x2 y2 0 <wf> <f> <Vpeak> <bias> 0 0.5` | **點 2 是正端**；`wf` 0 = DC、1 = 正弦；`Vpeak` 是峰值不是峰對峰 |
| BJT | `t x1 y1 x2 y2 0 <1=NPN，-1=PNP> 0 0 <β>` | **基極在點 1**；集極在 (x2, y2−16)、射極在 (x2, y2+16)，旗標 1 會上下對調；後面可再接模型名 `default` |
| MOSFET | `f x1 y1 x2 y2 0 <Vt> <β>` | **閘極在點 1**；汲極在 (x2, y2−16)、源極在 (x2, y2+16)；旗標 1 = P 通道；例 `f 208 176 256 176 0 1.5 0.02` |
| 滑桿 | `38 <元件序號> 0 <min> <max> <標籤> <step>` | 元件序號 = 該元件是第幾個元件行（從 0 數，`$`／`o`／`38` 不算）；編輯項 0 = 電壓源的電壓 |
| 示波器 | `o <元件序號> <speed> 0 <flags> 5 0.1 <位置> <標籤>` | `flags` 4219650 = 顯示電壓、峰值、刻度、自動縮放、RMS、P-P；要同時顯示電流用 4219651；`speed` 64 適合 60 Hz，20 Hz 用 128 |

## 佈局要點

- 橋式整流用菱形：交流端接左右頂點、負載放菱形**內部**（頂點到底點的垂直線），電源的回線繞外圍。兩條弦必須一內一外，否則一定交叉。
- 一個端點已有導線時，第二條線要接到**同一端點座標**（例如負載與電容並聯時共用節點座標）。
- 標籤（滑桿、示波器）不能含空白；需要空白用 `\s`。
- 三腳元件（BJT、MOSFET）的腳位方向一定用 `--check` 截圖核對，畫錯方向模擬不會報錯、只會給錯波形。

## 觀察要點寫進筆記時的用語

黃點 = 電流方向與大小；導線顏色 = 電位（綠正、紅負、灰零）；右鍵元件 → 編輯可改值；示波器格內文字有 Max、P-P、RMS。**只抄形狀、不抄數值**：預設二極體模型與實體型號不同。

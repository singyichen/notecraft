# Tinkercad Circuits 接線配方寫法與已知陷阱

Tinkercad 沒有 API，作者要自己拖；本 skill 的產出是**讓作者三分鐘拖完的配方表**，不是代拖。

## 配方表格式（每個實驗一張）

| 步驟 | 從 | 到 | 備註 |
| --- | --- | --- | --- |
| 1 | Power Supply **+** | Resistor 一端 | 電源先設 0 V、電流上限 0.1 A |
| … | | | |

規則：一列一條線；端點用元件庫的中文名＋端子名（正極／負極、陽極／陰極、端子 1／端子 2、紅／黑探棒）；儀器設定寫在備註；並聯元件標明「與 X 並聯」。

## 元件庫名稱（繁中介面）與設定欄位

| 元件 | 搜尋名稱 | 屬性面板 | 注意 |
| --- | --- | --- | --- |
| 直流電源 | 電源供應器 | 電壓、電流（上限） | 搜尋英文 `Power Supply` 找不到，用中文 |
| 訊號產生器 | 函數波產生器 | 波形、頻率、Amplitude、DC offset | **Amplitude 是峰對峰值**：講義 10 Vpp 就填 10 |
| 示波器 | 示波器 | Time per division、Volts per division | 兩支探棒**浮接**，可任意跨接；60 Hz 用 5 ms/div |
| 三用電表 | 萬用表 | 模式：安培數／電壓／電阻 | 量電流串聯、量電壓並聯 |
| 二極體 | 二極體 | 只有名稱 | 色環端是陰極；不分型號，通用模型導通電壓約 0.5 V |
| 齊納 | 稽納二極體 | Zener 電壓 | 依助教給的型號填 |
| 電阻 | 電阻 | 數值＋單位下拉 | 在「基本」分類第一格 |
| 電容 | 電容／極性電容 | 電容值 | 極性電容正極朝電源側 |
| BJT | NPN 電晶體 (BJT)／PNP 電晶體 (BJT) | 名稱 | 在「基本」分類；三隻腳懸停會顯示 射極／基極／集極，配方表一律寫腳名不寫左右 |
| MOSFET | 搜尋 MOSFET（nMOS／pMOS） | 名稱 | 腳位同樣以懸停提示為準（閘極／汲極／源極） |

接線方式：點一個端子 → 移動 → 點另一個端子；中途在空白處點一下可加折點。端子懸停會顯示名稱提示（正極／陽極／端子 2）。

## 版面要照講義投影片的畫法

作者的老師用 Tinkercad.pdf 第 6 頁那種畫法，配方與截圖都比照：

- 元件**橫插**在麵包板上半區（f–j 列），兩腳落在不同欄；不要點對點拉線、不要讓元件懸在板外。
- 正負極走上方電源軌（− 在上、+ 在下的紅線列），電源或電池放板子左側，兩條線接到軌道左端。
- 軌道到元件用**短直跳線**（例如 + 軌第 5 欄 → j5），同一欄的 f–j 五個孔是同一節點，串聯元件就共用一欄。
- 儀器（電表、示波器）放板子上方或側邊，探棒直接點到孔或軌道；截圖時開著模擬讓讀值顯示。
- 配方表寫「元件、插在哪裡（列＋欄）、備註」，而不是「從哪個端子到哪個端子」。

## 代操作（作者要求時才做）的技術備忘

`scripts/tinkercad/` 有一個 Playwright 常駐程式：`daemon.js` 用本機 Chrome 開獨立設定檔（作者要在該視窗登入一次），`run.sh <name> <<'JS' … JS` 把一段以 `page`、`ctx`、`D` 為變數的程式丟給它執行並回傳 JSON；`build-lab1-exp1.js` 是完整的實驗一重建範例。踩過的坑：

| 現象 | 原因與做法 |
| --- | --- |
| 元件庫搜尋英文找不到 | 用繁中名稱；`電阻` 直接在「基本」分類第一格，不要搜尋 |
| 放第二個元件後所有座標失準 | Tinkercad 會自動「縮放至適合」；每一步都從 DOM 重讀幾何：排孔是 `g.cgfx__breadboard-round`（14 列 × 30 孔，第 3–12 列是 j–a），電表探棒是 `.cgfx__wire-terminal`，電源端子要靠懸停提示（正極／負極）掃出來 |
| 按一次 `R` 元件變斜的 | 旋轉一次只有 30°，轉 90° 要按三次；放完用 bbox 中心對齊目標孔中點，最多修正 4 次 |
| 二極體方向相反 | 懸停兩端讀 陽極／陰極，反了就再按六次 `R` |
| 接線失敗 | 端點已有線頭時點旁邊 3 px；點孔要點圓心；中途在空白處點一下可加折點 |
| 屬性面板輸入框點不到 | 用 `click({ force: true })`；面板在右上角，電壓在 y≈186、電流在 y≈222 |
| 清空畫布沒清乾淨／誤刪電源 | 先 `goto` 重新載入，點畫布空白處再 `Meta+A`、`Delete`，用元件數為 0 驗證；不要用點線中點來刪線 |
| 點到面板的「?」跳回儀表板 | 取消選取一律點畫布左下角空白 (60, 870) |
| 線路圖檢視沒有電表 | Tinkercad 線路圖不畫儀器，結報電路圖另外用講義圖或 KiCad |

## 一定要寫進筆記的陷阱

1. **實體示波器不浮接**：訊號產生器的 − 與示波器每個通道的地夾都接大地。橋式整流的輸入端與輸出端沒有共同節點，兩個通道同時接會用大地把一顆二極體短路。實驗四類型的電路要寫「先量 Vin 再量 Vout」或「兩地夾同接 N、用 Math CH1 − CH2」。
2. **講義參數與齊納電壓不合**時要點破：5 Vpp 經橋式後只剩約 1.1 V，任何常見齊納都不會導通，模擬連結改用概念圖條件並說明。
3. Tinkercad 的電表是理想儀器（電壓檔內阻無限大、電流檔內阻零），實測會差；這正好是講義「解釋差異」題的素材。
